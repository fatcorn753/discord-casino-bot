# ペリカカジノ（Discord ミニゲーム Bot）

ゲーム内の仮想通貨「**ペリカ**」で遊ぶ、友達向けのお遊びカジノです。
**現実のお金とは一切関係なく、換金もできません。** 課金や購入の仕組みもありません。

**ペリカは「サーバーごと」に別々です。** 残高・デイリー・ショップの景品・成績・履歴は、サーバーごとに独立していて、別のサーバーには持ち込めません（初めて遊ぶサーバーでは、そこで3,000ペリカから始まります）。

## 遊び方

| コマンド | 内容 |
|---|---|
| `/ペリカ デイリー` | 1日1回のボーナス。連続で受け取るほど増える（1,000〜1,900ペリカ） |
| `/ペリカ 残高` | このサーバーでの残高・順位・成績 |
| `/ペリカ ランキング` | このサーバーで、ペリカの多い順 |
| `/ペリカ 送金` | このサーバーの友達に送る（手数料10%・1日の合計20,000ペリカまで。3回以上ゲームで遊んだ人だけ。ゲーム中は送れない） |
| `/ペリカ 履歴` | 最近の増減（自分だけに見える） |
| `/暗号 価格` `チャート` `買う` `売る` `保有` `チャート掲示` | CSトークン（1種類）の売買。価格は**全サーバー共通**で1分ごとにランダムに動き（期待値は変わらない。平均への引き戻しなどの偏りは入れていない）、売買の手数料なし。小数（0.001枚）で買える。チャートは文字のグラフで、`チャート掲示` で自動更新の掲示もできる（サーバー管理か Bot の持ち主）。ゲーム内の通貨で、現実のお金とは無関係 |
| 結果の下の「🔁 もう一度」 | コイン・スロット・ルーレット・パチンコの結果に出るボタン。同じ額、または倍の額でもう一度遊べる（遊んだ本人だけ・90秒間） |
| `/ペリカ ミッション` | 今日のミッション3つと進み具合。達成すると自動でペリカがもらえ、3つ全部で+500ボーナス（毎日0時に入れ替わり、全員共通）。賭け金100ペリカ以上のゲームだけが数えられ、連勝ミッションはその日の分だけで数える。遊ぶと連勝も記録され、結果に🔥が付く |
| `/ペリカ ランキング掲示` | ランキングを1つ投稿して、**1分ごとに自動で書き換える**（サーバー管理）。止めるのは `ランキング掲示解除` |
| `/カジノ チンチロ` | 🎲 地下チンチロ。親と勝負、目が出なければ3回まで振れる |
| `/カジノ パチンコ` | 🎰 地下パチンコ。玉が落ちてリールが回る演出つき |
| `/カジノ スロット` | 🍒 3つ揃えば大きく増える |
| `/カジノ コイン` | 🪙 表裏を当てる（当たりで1.95倍） |
| `/カジノ ブラックジャック` | 🃏 ヒット・スタンド・ダブル |
| `/カジノ ルーレット` | 🎡 色・偶奇・範囲・数字に賭ける |
| `/ショップ` | 🛍️ ペリカで称号・カードの色/アイコン・消耗品・名前の色を交換（下の「ショップ」参照） |
| `/ヘルプ` | 遊び方の一覧 |

各サーバーで初めて遊ぶとき、**3,000ペリカ** がもらえます。賭け金は **10〜100,000ペリカ**。同時に遊べるゲームは1つだけです。
ペリカが尽きても、`/ペリカ デイリー` で毎日もらえます。

### チンチロのルール
サイコロ3個を振って役で勝負します。親（ディーラー）が先に振り、そのあとあなたがボタンで振ります。

| 役 | 内容 | 勝ったときの倍率 |
|---|---|---|
| ピンゾロ | 1-1-1 | 5倍 |
| 嵐（アラシ） | 2〜6のゾロ目 | 3倍 |
| シゴロ | 4-5-6 | 2倍 |
| 目 | ペア＋1つ。残った1つが目の数（6が最強） | 1倍 |
| 目なし | 役なし。3回まで振り直せる | — |
| ヒフミ | 1-2-3。**負け役**で、負けると2倍払い | — |

- 強さは「ピンゾロ ＞ 嵐 ＞ シゴロ ＞ 目 ＞ 目なし ＞ ヒフミ」。同じ強さは引き分け（賭け金が戻る）。
- 負けたとき、相手の役が嵐・ピンゾロなら 3倍・5倍払い。賭け金のほかに払う分は残高から引かれます。そのため、**チンチロは残高が賭け金の5倍以上あるときだけ**遊べます（全財産を賭けると損失が頭打ちになる抜け道を防ぐため）。
- **目なし同士は親の勝ち**です（これが胴元の取り分）。

結果の乱数は OS の乱数（`SystemRandom`）で、予測や再現はできません。払い戻しの端数（1.95倍や0.3倍など）は切り捨てです。

## サーバーの承認（友達のサーバーだけで遊ぶ）
`config.json` に `"require_approval": true` と、自分のユーザーIDを入れた `owner_ids` を設定すると、**Bot が新しいサーバーに追加されたとき、持ち主に DM で通知が届きます**。

1. 友達が招待 URL から Bot を追加します。
2. 持ち主に DM が届きます（サーバー名・ID・持ち主・メンバー数つき）。ボタンは **【許可する】** と **【断って退出させる】** です。
3. 【許可する】を押すと、そのサーバーIDが記録に保存され、**再起動なしですぐ**遊べるようになります（サーバー側にも通知します）。
4. 承認前のサーバーでコマンドを使うと「承認待ちです」と表示され、持ち主にもう一度（1時間以上あけて）通知されます。

- **持ち主のコマンド**: `/ペリカ サーバー一覧`（許可・承認待ち・断った一覧）、`/ペリカ サーバー許可 サーバーid`（IDを指定して許可。まだ参加していないサーバーも事前に許可できます）、`/ペリカ サーバー取消 サーバーid`（許可を取り消して Bot を退出させます）。
- 持ち主は、承認待ちのサーバーの中でもコマンドを使えます（そこから許可を出せます）。
- DM を受け取れない設定の場合は、`/ペリカ サーバー一覧` で承認待ちを確認し、`サーバー許可` で許可してください。
- ボタンは Bot を再起動しても動きます。一度断ったサーバーは、追加し直すと、もう一度確認が届きます。

## ランキング掲示板（自動で更新）
`/ペリカ ランキング掲示 チャンネル:#ランキング` を一度実行すると、Bot がそのチャンネルにこのサーバーのランキング（上位10人・称号つき）を投稿します。以降は **同じメッセージを1分ごとに書き換える** ので、新しい投稿は増えません。

- 設定できるのは「サーバー管理」権限を持つ人と Bot の持ち主（`owner_ids`）で、**1サーバーに1つ**です。もう一度実行すると、前の掲示板を削除して新しく置き直します。
- メッセージが消されても、次の更新で自動的に投稿し直します。チャンネルが消えたら、掲示は自動で止まります。
- 止めるときは `/ペリカ ランキング掲示解除`（投稿も削除します）。Bot が再起動しても、掲示は続きます。
- Discord の仕様上、Bot が編集できるのは **Bot 自身が投稿したメッセージだけ** です（人が貼ったメッセージは編集できません）。
- 載るのは、そのサーバーで遊んだ・コマンドを使った人だけです。

## ショップ（景品の交換）
景品はすべて **ゲーム内・サーバー内で完結するもの** です。現実の価値があるもの（Nitro・ギフトコード・現金など）は一切扱いません。買った景品は、**買ったサーバーの中だけ**で使えます。

| 種類 | 内容 | 値段の目安 |
|---|---|---|
| 🏷️ 称号 | 残高カードとランキングの名前の横に表示される（「ざわ…ざわ…」「地下の帝王」など） | 2,000〜100,000 |
| 🎨 カードの色 / 🖼️ アイコン | `/ペリカ 残高` のカードの色・アイコン | 3,000〜5,000 |
| 🎟️ 消耗品 | **デイリー2倍券**（次のデイリーが2倍）、**保険券**（次に負けたゲーム1回で、賭け金の半分が戻る。**最大1,000ペリカ**） | 2,000〜3,000 |
| 🌈 名前の色（ロール） | サーバー内の名前の色が変わる（12色） | 各 20,000 |

- `/ショップ 一覧` → `購入` → `使う`（身につける）の順に使います。`持ち物` で確認、`外す` で外せます。
- 称号・カード・名前の色は一度買えばずっと使えます（消耗品は使うとなくなります）。
- 10,000ペリカ以上の買い物は確認ボタンが出ます。景品は人に渡せません。
- **ゲームの途中は、買い物も消耗品の使用もできません**（結果を見てから保険券を使う、などを防ぐため）。
- 保険券は、勝ちや引き分けでは使われず、**負けたとき**に1枚使われます。戻る額は券の値段より少ない（最大1,000ペリカ）ので、買って使うだけで増えることはありません。チンチロの倍払いの追加分は対象外です。
- 買い物・送金は、確認ボタンの待ち時間も含めて「プレイ中」として扱い、その間はゲームを始められません。

### 称号をニックネームに付ける
`/ショップ 称号表示 表示:ニックネームに付ける` を実行すると、装備中の称号が **ニックネームの後ろ** に付きます（例: `たつ【ざわ…ざわ…】`）。メッセージの名前の横に表示されます。

- **自分で選んだ人だけ**、そのサーバーでだけ有効です（初期は付けません）。`付けない（元に戻す）` で、元のニックネームに戻ります。
- 称号を付け替えたり外したりすると、ニックネームも自動で変わります。ONにしている複数のサーバーにも反映されます。
- Bot に **「ニックネームの管理」権限** が必要です。**サーバーの持ち主と、Bot のロールより上のロールの人は、Discord の仕様で変えられません**（その場合は理由を案内して、設定は有効になりません）。
- ニックネームは32文字までなので、長い名前の人は、称号を残して名前の後ろが切れて付きます。**付ける前のニックネームは記録しているので、称号を外すと、切れる前の名前に完全に戻ります。**
- 自分でニックネームを変えると、称号が消えることがあります。もう一度 `/ショップ 使う` で付け直せます。自分で付けた `【…】` は消しません（ショップの称号と同じ名前のものだけを外します）。
- 一度も ON にしていない人のニックネームには、Bot は触りません。Bot がサーバーから外れると、そのサーバーの設定は消えます。

### 名前の色（ロール）について
- Bot が「ペリカ・赤」のようなロールを作って付けます。**権限は一切持たない、色だけのロール**です。同じ名前で権限を持つロールがすでにあるサーバーでは、安全のため使わず、名前を変えるよう案内します。Bot が付け外しするのは、この色ロールだけです。
- Bot に **「ロールの管理」権限** が必要です。招待URLの権限は `permissions=402672640` にしてください（すでに招待済みなら、そのURLをもう一度開いて承認すると権限が追加されます）。
- サーバーの名前の色は、**ロール一覧で一番上にある「色つきのロール」の色** になります（色が「デフォルト」のロールは無視されます）。
  色ロールは Bot のロールのすぐ下に置くので、それより上にある運営用ロールなどの色は優先されます。
  すでにある別のロール（例: シークレットチャンネル用）に色が付いていて、それが色ロールより上にある場合は、そちらの色が優先されます。色ロールを優先させたいときは、そのロールの色を「デフォルト」にするか、色ロールより下に動かしてください。
- Bot のロールは、色ロールを動かせるように、サーバー設定のロール一覧で十分上（運営用ロールの直下など）に置いてください。

## 導入手順

### 1. Discord 側の準備
1. [Discord Developer Portal](https://discord.com/developers/applications) で **「新しいアプリケーション」** を作ります。
2. **「Bot」** を開き、**「トークンをリセット」** でトークンをコピーします（一度しか表示されません。他人に見せないでください）。
3. **特権インテントは不要です**（メッセージの内容もメンバー一覧も読みません）。

### 2. 設定と起動
```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp config.example.json config.json      # Windows: copy config.example.json config.json
.venv/bin/python main.py                # Windows: .venv\Scripts\python main.py
```
`config.json` を編集します。

| 項目 | 説明 |
|---|---|
| `token` | Bot トークン（必須） |
| `allowed_guild_ids` | あらかじめ許可するサーバーのID一覧。`require_approval` が false のときは、空 `[]` ならどのサーバーでも遊べ、空でなければこの中だけ遊べます |
| `require_approval` | `true` にすると**承認制**になります。許可リスト以外のサーバーは、持ち主が承認するまで使えません（下の「サーバーの承認」参照）。初期は `false` |
| `legacy_guild_id` | サーバーごとに分ける前の古い記録がある場合に、それを引き継ぐサーバーのID。省略すると `allowed_guild_ids` の先頭を使います。古い記録がないとき（新規）は不要です |
| `owner_ids` | Bot の持ち主のユーザーID。`/ペリカ 付与` とサーバーの承認ができる人です（複数可） |
| `test_guild_id` | 開発用。指定するとそのサーバーだけにコマンドが即時反映されます。**本番では `null`**（別の場所の Bot が登録したコマンドと重複して、同じコマンドが2つ表示されます） |
| `utc_offset_hours` | デイリーの日付の境目の時差。日本は `9`（日本時間の0時に切り替わります） |

サーバーID・ユーザーIDは、Discord の「設定 → 詳細設定 → 開発者モード」をオンにして、右クリックの「IDをコピー」で取れます。

### 3. サーバーへ招待
`CLIENT_ID` を、Developer Portal の「一般情報」にあるアプリケーションIDに置き換えて開きます。

```
https://discord.com/oauth2/authorize?client_id=CLIENT_ID&scope=bot+applications.commands&permissions=402672640
```
必要な権限は「チャンネルを見る」「メッセージを送信」「埋め込みリンク」と、ショップ用の「ロールの管理」（名前の色）・「ニックネームの管理」（称号の表示）です。ショップを使わないなら `permissions=19456` で足ります。

## 仕組みと安全
- **賭け金は開始時に預かり**、結果が決まったら精算します（スロット・パチンコなどは、演出の前に精算するので、演出の途中でメッセージを消しても結果は変わりません）。残高の増減は1回の処理で行い、台帳（履歴）に記録します。
- 連打や同時操作でペリカが増減しないよう、同じ人は同時に1つのゲームしか始められません。
- **Bot が途中で止まった場合、預かっていた賭け金は次の起動時に全額返ります。**
- ボタンは賭けた本人だけが押せます。放置すると、チンチロは「目なし」、ブラックジャックは「スタンド」として自動で精算します。
- 保存するデータ: サーバーごとの、ユーザーID・残高・成績・増減の履歴・持ち物。メッセージの内容は読みません。保存先は `data/casino.db` です。

## 運用
- 常時動かす場合は、`systemd` などで自動起動・自動再起動にします（管理補助bot と同じ要領）。**同じトークンで2か所から起動しないでください。**
- データのバックアップは、Bot を止めてから `data/` をコピーします。
- トークンを漏らしたら、すぐ Developer Portal で再発行して `config.json` を差し替えてください。`config.json` と `data/` は `.gitignore` 済みです。
