# ペリカカジノ（Discord ミニゲーム Bot）

ゲーム内の仮想通貨「**ペリカ**」で遊ぶ、友達向けのお遊びカジノです。
**現実のお金とは一切関係なく、換金もできません。** 課金や購入の仕組みもありません。

**ペリカは「サーバーごと」に別々です。** 残高・デイリー・ショップの景品・成績・履歴は、サーバーごとに独立していて、別のサーバーには持ち込めません（初めて遊ぶサーバーでは、そこで3,000ペリカから始まります）。

### チンチロのルール
サイコロ3個を振って役で勝負します。親（ディーラー）が先に振り、そのあとあなたがボタンで振ります。

| 役 | 内容 | 勝ったときの倍率 |
|---|---|---|
| ピンゾロ | 1-1-1 | 5倍 |
| 嵐（アラシ） | 2〜6のゾロ目 | 3倍 |
| シゴロ | 4-5-6 | 2倍 |
| 目 | ペア＋1つ。残った1つが目の数（6が最強） | 1倍 |
| 目なし | 役なし。3回まで振り直せる | — |
| ヒフミ | 1-2-3。**負け役**で、負けると相手の役の倍率が**さらに2倍**（例: シゴロ対ヒフミは4倍） | — |

- 強さは「ピンゾロ ＞ 嵐 ＞ シゴロ ＞ 目 ＞ 目なし ＞ ヒフミ」。同じ強さは引き分け（賭け金が戻る）。
- 負けたとき、相手の役が嵐・ピンゾロなら 3倍・5倍払い（ヒフミで負けるとその2倍で、最大10倍）。賭け金のほかに払う分は、まず残高から引かれ、足りない分は強制執行（下の「借金と身分」）のあと、**帝愛への借金**になります。
- 借金は、**収入（ゲームの純利益・デイリー・ミッション報酬・受け取った送金など）の3割が天引き**されて返ります。借金がある間は、ショップの購入・証券の購入・送金・クイズの出題はできません。ランキングの総資産は借金を引いた額です。くわしくは「借金と身分」の節。
- **目なし同士は親の勝ち**です（これが胴元の取り分）。

結果の乱数は OS の乱数（`SystemRandom`）で、予測や再現はできません。払い戻しの端数（1.95倍や0.3倍など）は切り捨てです。

## 証券の銘柄と相関

| 銘柄 | 値動きの大きさ（1分） | 1日の標準偏差 | 性格 |
|---|---|---|---|
| 🪙 CSトークン | 0.12% | 約4.6% | 暗号資産ほどの値動き。ほかの銘柄の基準 |
| 🏭 TEIO重工 | 0.07% | 約2.7% | 大型株。CSと正相関（+0.6）。GOLDとは逆（−0.5） |
| 🧪 NUMAバイオ | 0.22% | 約8.3% | 仕手株。ほかとはほぼ無相関（+0.05） |
| 🥇 GOLD地金 | 0.04% | 約1.5% | CSと逆相関（−0.6）の避難先 |

- 乱数は、分散共分散行列 Σ（σᵢσⱼρᵢⱼ）のコレスキー分解で相関をつけ、`P ← P·exp(μᵢ − Σᵢᵢ/2 + 揺れ)` と動かします。−Σᵢᵢ/2 の補正で、揺れだけでは期待値は変わらず、向きを読んで儲けることはできません。
- **期待成長率（μ）**: リスクを取って株を持つ理由として、銘柄ごとに、ごく小さな期待成長率を付けています（**1日あたり** CS 0.8%・TEIO 0.7%・NUMA 1.0%・GOLD 0.3%）。通常債（72時間で+4%＝1日約1.3%）より控えめで、債券が1人30,000までなのに対し、株には上限がないので、大きな資産の運用先になります。際限なく値上がりしないよう、価格が**開始価格の8倍**に近づくほど成長率は弱まり、8倍で0になります。
- 約1日に2回、**有事**（全銘柄が同じ向きに急騰・急落）が起こります。CSで±1.5〜3.5%、ほかの銘柄は値動きの大きさの比（最大1.5倍）をかけた分だけ動きます。有事には逆相関のヘッジが効かなくなります。
- **値幅制限（ストップ高・ストップ安）**: 画面の価格は、**24時間前の価格から上下30%まで**しか動きません。ただし裏には、制限のない**理論価格**があって、有事やイベントで、その外まで突き抜けて動きます。理論価格が値幅の外にいる間は、画面の価格が値幅の端に**張り付き**（🚀ストップ高・🚨ストップ安。市況の画面に出ます）、翌日になっても、まだ理論価格が外なら、次の値幅の端にまた張り付きます（**2連ストップ**）。
  - **ストップ安に張り付き中**は、買い手がいないので、**現物の売却・買い建て（ロング）の決済・持っているコールの売却**が、約定しません（買いと、空売りの買い戻しは通ります）。
  - **ストップ高に張り付き中**は、売り手がいないので、**現物の買い・買い建ての新規・空売りの買い戻し**が、約定しません（売りと、空売りの新規は通ります）。
  - **ロスカットや破産の整理は、張り付き価格で執行されます**（ロックされません）。逃げたくても逃げられない恐怖と、踏み上げの怖さが、ここにあります。
- **金額の候補**: `/証券 注文` の `金額` の欄は、何も打っていないときに、**残高の25%・50%・75%・100%**の候補を出します（選ぶだけで、手持ちに対する割合で買えます）。
- **信用金利（借入金利・貸株料）**: 信用取引の建玉を持っている間、**金利が担保から自動で引かれ**ます（日利）。**信用買い**は、借りている額（建てた総額 − 担保）に **0.1%/日**（借入金利）、**空売り**は、建てた総額に **0.05%/日**（貸株料）です。1分ごとに数え、**10ペリカ貯まるごと**に引きます。担保が減るので、維持率も少しずつ下がります。引いた金利は**帝愛の銀行に入り、預金者の利回り**になります。履歴に「帝愛の信用金利」が残ります。空売りの売却代金への受取金利（ショートリベート）は、**付けていません**（通常債の利回りを払うと、空売りと現物買いを組むだけで、ノーリスクでペリカが増えてしまうため）。
- **利益への税（キャピタルゲイン税）**: 現物の売却と信用建玉の決済で**利益が出たときだけ**、その利益から帝愛が**超過累進**で天引きします（1回の決済ごと）。**1万ペリカまでは非課税**、1万超〜10万の部分は3%、10万超〜100万の部分は7%、100万超の部分は12%です（たとえば利益2万なら、税は300）。損失には、かかりません。強制執行・ロスカットの決済にも、かかりません。税は**帝愛の銀行に入り、預金者の利回り**になります（預金者がいなければ、銀行の手元に入ります）。履歴に「帝愛のキャピタルゲイン税」が残ります。オプション・債券には、かかりません。
- `/証券 市況` に、直近24時間の実測の相関が出ます（チャートにも、その銘柄とほかの銘柄の連動が出ます）。
- 旧版の `/暗号`・`/債券` と、買う・売る・空売り・買い戻し・価格・チャートのコマンドは、`/証券 注文`・`保有`・`市況`・`決済` の4本に集約しました。以前のCSトークンの保有・空売り・履歴は、そのままCSトークンとして引き継がれます。
- 信用買い・クロスマージン（口座ぜんたいの維持率・現物と債券を担保にする仕組み）は、下の「信用取引」にあります。

## 信用取引（信用買い・空売り）

`/証券 注文` で、銘柄・金額・注文種別（**信用買い**＝上がると儲かる / **空売り**＝下がると儲かる）・レバレッジ（1・2・3・5倍）を選びます（建てる総額を金額で指定します）。

- 預ける**担保 = 建てた総額 ÷ レバレッジ**です。残高から預かります。残高の現金は、建玉の担保には数えません（現金は、建玉の損失に巻き込まれません）。
- 閉じるときは、`/証券 保有` のボタン（全部）か、`/証券 決済`（半分・全部）を使います。戻る額は「担保 + 損益」です。
- 建玉は、1人につき銘柄・向きごとに1つです。追加で建てると、平均の建値でまとめられます。**同じ銘柄の買い建てと売り建ては、同時に持てません**。借金があるときは建てられません。
- 手数料も金利もありません。価格の決まり方は現物と同じで、期待値は変わりません（必勝法はありません）。
- ランキングの総資産には、担保と含み損益が入ります（建玉ごとに0未満にはしません）。

### 口座の維持率（クロスマージン）

強制決済は、建玉ごとではなく、**口座ぜんたい**で判定します（`/証券 保有` の最下部に表示）。

- **有効証拠金** = Σ（建玉の担保 + 含み損益） + **代用有価証券の評価**
- **必要証拠金** = 20 × √(wᵀΣw)。w は銘柄ごとの建玉額（信用買いは＋、空売りは−）、Σ は銘柄の分散共分散行列（`core/market.py`）。20 は、1分の値動きの約2.6σを、約60分ぶん見込んだ係数です
- **維持率** = 有効証拠金 ÷ 必要証拠金。相関のある建玉は値動きが打ち消し合うので、必要証拠金が小さくなります（CSの買いとTEIOの売りを組み合わせると、ほとんど要らなくなる）。値動きの大きい銘柄（NUMAバイオ）は必要額が大きく、5倍は担保だけでは建てられません
- **代用有価証券**: 現物は売った手取りの**80%**、通常債は元本の**95%**、ジャンク債は元本の**50%**を、有効証拠金に数えます（売らずに持ったまま担保になる）
- 🟢150%以上 / 🟡130〜150% / 🔴130%未満。**建てるとき・担保の現物を売るとき・担保の債券を売るとき**は、そのあとの維持率が**130%以上**でないと受け付けません
- 維持率が**100%を下回る**と、1分ごとの価格更新のときに、**含み損の大きい建玉から順に全部決済**し、100%に戻ったところで止めます（連鎖ロスカット）。現物・債券は、ロスカットでは売りません
- 急変動で、決済しても担保を超える損失が出たときは、その分を**現金 → 現物 → 債券の順に取り立て**、足りなければ帝愛の借金になります（強制執行と同じ）
- 強制執行・自己破産のときは、空売りも信用買いも、現金より先に強制決済されます

## オプション（爆騰コール・暴落プット）

`/証券 注文` で、注文種別に **爆騰コール**（上がると当たり）か **暴落プット**（下がると当たり）を選び、銘柄と**掛け金**を入れるだけです。専門用語の入力はありません。

- **条件は固定**です。満期は**6時間後**、当たりの基準（権利行使価格）は、**買った時点の価格から、銘柄ごとの既定の割合ぶんずらした値**（コールは上、プットは下。既定は GOLD 1.5%・TEIO 2%・CS 3%・NUMA 5%。値動きの大きい銘柄ほど遠い）です。`/証券 注文` の**`目標割合`**（1〜50%）で、自分で決められます（遠いほど、1口が安く、当たりにくく、当たると大きい。ペア・ワラントにはありません）。
- **損失は、払った掛け金だけ**です。途中のロスカットも追証もありません（信用取引との違い）。
- 満期の価格が基準を超えて（コール）／下回って（プット）いれば、その差が配当です（1枚あたりの差 × 口数）。満期の価格で**自動で決済**され、外れれば掛け金は戻りません。配当は、掛け金の**50倍まで**です。
- 満期の前でも、`/証券 保有` のボタンか `/証券 決済` で、**いまの値段で売れます**（買った直後は、手数料の分だけ少し損）。値動きが有利なほど高く売れます。
- 注文の画面に、**勝利条件**と、価格が +10%・+20% 動いたときの**想定リターン**が出ます。

### 値段の決まり方
- Black-Scholes の式で、公正な値段を決めます。この市場は、どの銘柄も**期待値が変わらない**ので、金利は 0 です（どちらにも有利な偏りがありません）。
- 分散は、1分ごとの揺れの合計に、**有事（急騰・急落）の分**を足したものです。値動きの大きい銘柄（NUMAバイオ）ほど高く、ほとんど動かない銘柄（GOLD地金）ほど安くなります。
- 買値は公正価格の **+1.5%**、売値は **−1.5%** です（往復で約3%）（この差は、銀行の収入になります）。公正価格がこの市場の動きと合うことは、シミュレーションで確かめてあります。
- 相手は**帝愛銀行**です。掛け金は銀行に入り、配当と売却代金は銀行が払います（手元の現金と預金の範囲まで。払い切れない分は、その分だけ減ります）。大当たりが出ると、銀行の準備率が下がります。
- 持てる掛け金は、**合計20,000ペリカまで**です。借金があるときは買えません。オプションは総資産（ランキング）に、いま売ったときの手取りで入り、強制執行・自己破産では、時価で売って充てられます。

### ペア・ワラント（2銘柄の勝ち負け）
`/証券 注文` で、注文種別に **ペア・ワラント** を選び、「銘柄」と「**相手**」の銘柄、掛け金を入れます。**6時間後に、銘柄の上昇率が、相手の上昇率を上回れば**当たりです（基準はなし）。
- 配当 = 想定元本 × max(0, 銘柄の上昇率 − 相手の上昇率)（掛け金の50倍まで）。市場全体が下がっても、銘柄が相手よりましなら当たります。
- 値段は **Margrabe の式**（交換オプション）です。2銘柄の**相対ボラティリティ** √(Σ_AA + Σ_BB − 2Σ_AB) で決まり、**強く連動する2銘柄ほど安く**（当たったときの倍率が高く）なります。有事（同じ向きに銘柄ごとの大きさで動く）と、ボラティリティ予告の分も、値段に入ります、**満期までに決算の発表がある銘柄は、その分の揺れも**、値段に入ります（決算の前後は、プレミアムが高くなります。メモがなくても、コールとプットの両方を買っても、得になりません）。
- 損失は掛け金だけです。満期前の売却や自動決済は、コール・プットと同じです。

### 裸売り（コール裸売り・プット裸売り）
オプションを、**売る側**に回ります。注文種別に「コール裸売り」「プット裸売り」を選び、銘柄と**証拠金**を入れます。
- 帝愛に売って、**プレミアム（売値）を今すぐ受け取ります**。同時に、**証拠金（行使価格 × 口数の20%）**を預けます（合計 20,000ペリカまで）。
- 満期の価格が行使価格を超えて（コール）／下回って（プット）**いなければ、プレミアムが丸ごと利益**で、証拠金も戻ります。相場が凪いでいれば、コツコツ稼げます。
- 超えたら、その差が**あなたの損失**で、証拠金から払います。**証拠金を超えた分は、帝愛の借金になります**（強制執行 → 借金 → 破産猶予の流れです）。コールは、理論上、損失が青天井です。
- 途中のロスカットはありません。満期の前に、`/証券 保有` のボタンか `/証券 決済` で、**買値で買い戻して**閉じられます（買い戻しの費用が証拠金を超えれば、その分は借金）。
- プレミアムは**帝愛銀行**が払います。銀行の利用可能現金が足りないときは、売れません。損失は、銀行の収入になります。
- 売るときは、必ず**確認ボタン**が出ます。借金がある間は売れません。裸売りの評価（証拠金 − 買い戻しの費用）は、総資産に入り、強制執行・自己破産では、買い戻して閉じられます。

### 市場イベント（`/証券 市況` に出ます）
どれも「必ず勝てる合図」ではありません。**大きく動く**ことが分かっても、上がるか下がるかは分かりません。

- **⚡ ボラティリティ予告**: 約5時間に1回、ランダムな銘柄に出ます。**予告の15分後から20分間、その銘柄の値動きが2倍**になります（期待値は変わらず、向きはランダムなまま）。予告が出ている間、`市況` に、その銘柄の**爆騰コール・暴落プットのワンクリックのボタン**が出ます（押すと、掛け金を入れる画面）。
  - オプションの値段は、予告の直後は、イベントの分を**4割だけ**織り込み、開始に近づくほど全部を織り込みます。早く気づいて仕込めば得で、遅いほど高くなります。
  - 終わってから60分は、次の予告が出ません。
- **📣 定期決算（毎週火曜 13:30）**: **TEIO重工** か **NUMAバイオ** のどちらかが、毎週、決算を発表します。**月曜 9:00 に、対象と発表の時刻が、告知チャンネルと `市況` に出ます**（方向と大きさは、発表まで、だれにも分かりません）。発表の瞬間に、裏の理論価格が、好決算なら**上へ**、悪決算なら**下へ**、一気に動きます（ふつうは ±8〜22%。**15%の確率で、±35〜60%の大サプライズ**）。サプライズは値幅制限（±30%）を突き抜けるので、**ストップ高・ストップ安に張り付き、翌日も続く（2連ストップ）**ことがあります。結果は、告知チャンネルに出ます。
- **🕴️ 裏情報メモ**: 次の決算の方向についての「極秘メモ」（本人にだけ見える）が、**2通りで手に入ります**。(1) **`/ペリカ デイリー` を受け取ったとき、10%の確率で**届きます（確度 70%・30%はガセ）。(2) **ショップの「🕴️ 帝愛市」**で、**裏情報メモ（決算）**を5,000ペリカで買えます（確度 80%・2割はガセ。**1つの決算に、1人1枚・サーバーで5枚まで**。持ち物には増えず、買うとその場でメモが見えます。代金は、帝愛銀行の収入です）。どちらも、1つの決算に、それぞれ1人1回までです。信じて仕込むか、黙っておくか、周りを煽るか、は、あなた次第です。
- **🔀 相関崩壊の警報**: ふつう連動する（または、逆に動く）2銘柄の、直近60分の値動きの差が、ふだんの揺れの**2.5倍**以上に開くと出ます（例: CSトークンだけが急騰して、TEIO重工が取り残されている）。差が縮むほうに賭ける人は、信用買いと空売りを組み合わせる手があります。
- **🎯 ロスカットが密集しているところ**: このサーバーの信用建玉の、強制決済のライン（口座の維持率が100%を割る価格）が、現在値の±10%以内に集まっているところを、銘柄・向きごとに合計で出します（誰の建玉かは出ません）。そこに届くと、連鎖して決済されます。

## 突発イベント

1日に1回、**日本時間の12時〜23:30のどこか**で、**1つのゲームだけ30分間**、勝ったときの勝ち分（払い戻し − 賭け金）が**1.5倍**になります。上乗せは1回につき最大10,000ペリカです。

- どのゲームで、何時に始まるかは、日付とサーバーごとに決まります（運営の設定は不要）。
- 開始と終了は、ランキング掲示のチャンネル（無ければサーバーのシステムチャンネル）に自動で投稿されます。メンションは付きません。
- Bot が止まっていて開始を逃した日は、告知もイベントも行いません（終了後に起動しても何も投稿しません）。
- 負けたときや引き分けには、何も付きません。

## クイズ（時事ネタ・豆知識で稼ぐ）

`/クイズ 挑戦` で、まだ答えていない問題が1問ずつ、自分だけに見える形で出ます。4択のボタンで答え、**正解すると問題ごとの報酬**（既定100ペリカ）がもらえます。

- 1問につき**1人1回だけ**です。不正解でもやり直せません。答えたあとに、正解と解説が出ます
- 公開された問題に誰かが答えると、その場で「⭕ 〇〇が正解！」「❌ 〇〇が不正解…」が**みんなに見える形で**出ます（選んだ答えと正解は出しません。解説つきの結果は本人だけに見えます）
- 選択肢の並びは、問題を登録するときに1回だけシャッフルして固定します（誰が見ても同じ並びです）
- 登録すると、**全サーバーの告知チャンネル**（ランキング掲示のチャンネル、無ければシステムチャンネル）に、問題文と A〜D のボタンが投稿されます。**その場でボタンを押して答えられます**（結果は本人だけに見えます）。再起動しても、押せます
- 問題は全サーバー共通です。報酬は、答えたサーバーの口座に入ります（借金があれば、収入の3割が天引きされます）
- 持ち主の問題の報酬はシステムが払います。稼げる量は、問題の数で決まります（回答数の上限は別にありません）
- 通常債の売却は、`/証券 保有` の売却ボタンか、`/証券 決済`（ポジションで債券の番号を選ぶ）で行います
- ミッション・連勝・週間ランキング・突発イベントには数えません

**みんなが出題する（`/クイズ 出題`）**

誰でも自分の問題を出せます。入力フォームに、問題文・選択肢（4行。1行目が正解）・解説・「報酬 / 期間」（例: `100 / 2日`。期間は省略可）・「正解・不正解の文言」（省略可）を入れます。
- **正解・不正解の文言**: 2行で、1行目が正解のとき、2行目が不正解のときの見出しの言葉です（各20文字まで）。「⭕ 正解！」「❌ 不正解…」の「正解！」「不正解…」の部分が、結果の画面とみんなに見える通知で差し替わります。省略した方は、今までどおり「正解！」「不正解…」です（片方だけも書けます）

- 問題には、**制作者の名前**（登録したときの表示名。持ち主の問題も同じ）が「出題: 〇〇」と出ます
- 問題は、出したチャンネルに投稿され、ボタンで答えられます。**そのサーバーの中だけ**に出ます（ペリカがサーバーごとの口座なので）
- 正解1人への報酬（**1ペリカ以上。上限なし**）は、**出題者本人のペリカから払われます**。払うたびに出題者の残高から引き、**残高が足りなくなったら、足りない分は出題者の借金**になります（回答者には報酬を全額払い、公開メッセージに「⚠️ 出題者の残高が足りないため…借金になりました」と出ます）。借金は、出題者に入るお金から先に自動で返済され、返し終わるまで、出題と送金ができません。借金の上限はありません
- **正解の報酬をもらえるのは、ゲームを3回以上遊んだ人だけ**です（複数アカウントでペリカを作るのを防ぐ、送金と同じ条件）。3回未満の人も正解にはなりますが、報酬はなく、出題者は払いません。出題者の受け取り（下）にも数えません。持ち主の問題には、この条件はありません
- **出題者は自分の問題に答えられません**。有効な期間は1分〜7日（「90分」「6時間」「2日」の形。空欄なら3日）で、正解者数の上限はありません
- **回答者が2人以上**になると、出題者にシステムから次の3つが入ります（2人に満たないと、出題報酬はありません）。**回答のたびに**、その時点の合計との差が**その場で**払われ、公開メッセージに「💰 出題者 +〇〇（累計 〇〇）」と出ます。正答率が40%から離れると合計が下がり、その差額は出題者の残高から戻されます（残高の範囲まで）。期限・取り下げのときは、最終結果をまとめて出します
  - **基本報酬** 100ペリカ × 倍率
  - **正答率ボーナス** 最大200ペリカ × 倍率
  - **参加報酬** 回答者1人につき「報酬」ぶん（報酬 × 回答者数）。上限なし。人気の問題ほど増えます
  - **倍率** は、報酬が高いほど基本とボーナスを増やします（√(報酬÷100)。報酬100で×1、400で×2、1000で約×3.2。25なら×0.5）
  - ボーナスと参加報酬には、正答率が**40%**に近いほど大きくなる係数がかかります（ちょうど40%で満額、そこから離れるほど減り、0%と80%以上では0）。誰も解けない問題や簡単すぎる問題では稼げません
  - 例（報酬100・回答10人）: 正答率40% → 支払い400、受け取り1,300（100＋200＋1,000）で **+900**。20% → +500。60% → +100。70% → −300（簡単すぎて正答率が上がると赤字）
  - 例（報酬1,000・回答10人・正答率40%）: 支払い4,000、受け取り316＋632＋10,000＝10,948で **+6,948**。報酬を上げるほど、黒字（と赤字）の幅が広がる「ハイリスク・ハイリターン」です
  - 正解者への報酬は、出題者の残高から払われます。報酬が高い問題は、出題者の残高が尽きると借金になります
- 結果（参加人数・正答率・出題報酬と、**正解者・不正解者の一覧**）は、問題を投稿したチャンネルに、出題者へのメンションつきで出ます
- 乱用を防ぐため、1人が**同時に出せるのは2問まで、24時間に3問まで**です。借金中は出題できません
- 不適切な問題は、持ち主が `/運営 クイズ 削除` で消せます（出題報酬は出ません）
- 数字は `core/quizpay.py` で調整できます

## 債券（通常債とジャンク債）

`/証券 注文` で、銘柄に債券（通常債・ジャンク債）を選び、金額（1,000ペリカ以上）を選ぶと、元本を先に預かります。満期になると、**自動で残高に入ります**（`/証券 保有` を開いたときにも反映します）。

| 種類 | 期間 | 利息 | 倒産 | 満期前の売却 | 元本の上限（合計） |
|---|---|---|---|---|---|
| 🏦 通常債 | 3日 | +4% | なし（元本保証） | できる（DCF の値段） | 30,000 |
| 🗑️ ジャンク債 | 1日 | +20% | 満期までに**20%の確率**（元本が戻らない） | できない | 10,000 |

- **通常債の売却（DCF）**: 満期の受取額を、残り時間 τ（時間）だけ割り引いた値段で、いつでも売れます。売値 = 満期の受取額 × exp(−0.001 × τ)。買った直後は元本の約97%（元本割れ）で、待つほど満期の受取額に近づきます。満期まで待つより、必ず少し安くなります（`core/bonds.py` の `SALE_DISCOUNT_PER_HOUR`）
- **ジャンク債の倒産（ポアソン過程）**: 満期のときの1回の抽選ではなく、**満期までのどの瞬間にも**倒産します。倒産の強さ（ハザード率）λ は、満期までに倒産する確率がちょうど20%になる値（λ = −ln(0.8) ÷ 24時間）で、1分ごとに「1−exp(−λ×経過時間)」の確率で抽選します。止まっていたあとにまとめて引いても、倒産する確率の合計は同じです。倒産すると、その時点で元本は戻りません。ジャンク債の期待値は約96%（(1−0.20)×1.20）で、運のゲームとして遊ぶ形です
- 銀行の準備率に連動した信用スプレッドは、#5 で足す予定です
- 借金があるときは買えません。預けている元本は、ランキングの総資産に含まれます
- `/証券 保有` に、持っている債券（`#番号`・満期・受取額）と、最近の決着（満期・倒産・売却）が出ます。決着の通知は出ません
- ミッション・連勝・週間ランキング・突発イベントには数えません
- 利率・期間・上限は `core/bonds.py` の数字を書き換えて調整します

## 抽選（持ち主が開催）

Bot の持ち主（`owner_ids`）が、Bot とのDMで `/運営 抽選 開催` を使って始めます。参加費は500以上（上限なし）で指定するか、省略すると500〜3,000のランダムです。募集時間は分で指定します（省略で60分）。

- 参加は、投稿の「🎟️ 参加する」ボタンです。**参加費は押した時点で先に引かれ**、全員同じ額です。借金があるときは参加できません
- 締切に、参加者から1人を等確率で選びます。当選者が、集めた参加費の**全額**を受け取ります（手数料なし）
- 参加者が2人に満たないとき、`/運営 抽選 中止` したときは、全員に全額を返します
- 投稿がコメントで流れたら、`/運営 抽選 再掲示` で告知チャンネルに出し直せます（古い投稿は消え、参加者はそのままです）
- 募集中は1サーバーに1つだけです。開催状況と参加者は保存され、Bot を再起動しても続きます（締切を過ぎていれば、起動後に結果を出します）
- 参加費を預けている間は、ランキングの総資産がその分だけ減って見えます
- ミッション・連勝・週間ランキング・突発イベントには数えません

## ペリカのお金の流れ

運営口座の仕組みは廃止しました（ユーザーが負けた分・勝った分は、どこにも記録されません）。デイリー・ミッション・初期支給は、そのまま残高が増えます。
- ペリカはゲーム内の数字で、現実のお金とは無関係です。現実のお金に換える、売る、買うといった使い方はできません

## 借金と身分（帝愛ファイナンス）
借金は、**帝愛ファイナンスからの借金**です（プレイヤー同士の `/貸付` とは別）。数字は `core/teiai.py` で調整できます。

- **強制執行**: チンチロの倍払いなどで払えないとき、**現金 → 空売り・信用買い → 証券（現物・全銘柄）→ 通常債（古い順）**の順に差し押さえて充て、それでも足りない分が借金になります。現金で足りれば、証券には手を付けません。結果の画面に、差し押さえたものが出ます。
- **種銭**: 借金があって手元が空になると、帝愛が**種銭 3,000ペリカ**を貸し付けます（借金に加わります）。「これで取り返してこい…！」手元が空でなくても、種銭の枠（3,000）に足りなければ、**いつでも枠まで借りられます**（`/ペリカ 帝愛` の「種銭を借りる」。借金になり、地下労働者に落ちます）。
- **帝愛の信用でダブル**: ブラックジャックのダブルで手元が足りないとき、不足分（**3,000ペリカまで**）を帝愛から借りて強行できます（確認ボタンつき。借金になります）。破産者・破産猶予中は使えません。
- **天引き**: 収入の**3割**が、借金の返済に天引きされ、残りは手元に残ります。ゲームは、賭け金は全額戻り、**純利益の3割だけ**です（負けや引き分けからは引きません）。デイリー・ミッション報酬・クイズの報酬・抽選の当選・受け取った送金・債券の利息も収入です。管理者の付与・借りたお金・賭け金の返金・証券や債券の売却は、収入ではありません。
- **帝愛の利息（トイチ）**: 借金には、**1日ごとに借金の1%**（10日で1割）が加わります（単利。日数を満了した分だけ）。しばらく来なかった人は、**1回に数えるのは10日分まで**で、超えた日は数えません（放置で借金が膨らまないように）。利息で借金が増えるのは **14,999ペリカまで**で、利息のせいで破産猶予に入ることはありません。履歴に「帝愛の利息」が残ります。借金がなくなると、数え始めの時刻は忘れます。
- **デイリーのピンハネ**: 借金中は、デイリーの**2割を帝愛が没収**します（借金の元本は減りません）。残りの3割が天引きされ、手元が種銭の枠（3,000）に満たなければ、枠まで貸し付けます。ピンハネは、**帝愛の胴元の口座**に入ります（下の「帝愛の胴元の口座」）。
- **返済**: `/ペリカ 返済` で、手元のペリカから、いつでも返せます（金額を省くと、返せる限り全額）。
- **身分**（`/ペリカ 残高` に出ます）: 🟢 **カタギ**（借金も延滞もない）／🟡 **地下労働者**（帝愛の借金か、貸付の延滞がある）／🔴 **破産者**（自己破産のあと、完済して7日たつまで）。
  - 借金や延滞で地下に落ちても、**連続ログインは途切れません**（デイリーを毎日受け取っている限り続きます）。
  - 地下労働者・破産者の間は、買った**称号・カードの色とアイコン・演出の変更品・コレクションが差し押さえ中**で、見えません（記録は残り、カタギに戻ると使えます）。残高カードには「🔒 差し押さえ中」と出ます。
  - **ニックネームの末尾に、`【地下労働者】` `【破産者】` が自動で付きます**（2分おきに確認。称号の表示を選んでいなくても付きます）。完済してカタギに戻ると、元のニックネームに戻ります。サーバーの持ち主・Bot より上のロールの人・Bot に「ニックネームの管理」権限がないサーバーでは、付けられません。ランキングでは、名前の横に 🟡 🔴 が付きます。
- **借金中の債券の満期**: 債券の満期で戻る元本は、借金があれば**全額が返済に充てられ**ます（利息は、収入として3割だけ天引き）。満期の元本で、天引きをのがれることはできません。
- **借金中の `/貸付`**: 帝愛の借金があっても、借りられます（借り換え）。回収の順番は、**帝愛 → 延滞中の `/貸付`（古い順）**です。借金中の送金・クイズの出題は、これまでどおりできません。
- **自己破産**（`/ペリカ 破産`。確認ボタンのあとに実行。**元に戻せません**）:
  1. **全財産（現金・空売り・信用買い・証券・債券）と、ショップの全品（称号・カード・演出・コレクション・消耗品）を差し押さえ**ます。売れないジャンク債と、ショップの品は、購入額（元本）の**50%**で換金します。
  2. 換金した合計を、**帝愛 → 貸付（古い順）**の順に配当します。あまれば、手元に残ります。
  3. **貸付の残りは免責**（貸した人の損）。**帝愛の借金は、残っていても10,000ペリカまで圧縮**されます（完全には消えません）。
  4. 身分が🔴**破産者**になり、**完済して7日たつまで、貸付を借りられません**。
  - 借金も貸付の借り入れもないと、破産できません。破産のあと、手元が空で借金が残るなら、種銭が貸し付けられます。
  - **少額の借金でも破産できます**（債務超過の基準はありません）。たとえば、財産が何もなく、借金100・手元0で破産すると、差し押さえるものが無いので借金は100のまま残り、そこへ種銭（3,000）が貸し付けられて、借金3,100・手元3,000になります。手元に運転資金が渡るので、すぐ勝負へ戻れますが、借金は増えます。
  - 破産すると、**名前の色ロールが外れ、ニックネームに `【破産者】` が付く**のは、その場で行います（権限や位置の都合で失敗したときは、2分おきの確認で付け直します）。
- **🚢 海外逃亡チャンス！！**（`/ペリカ 帝愛` の画面のボタン）: 帝愛の借金が**5,000ペリカ以上**のとき、確認のあとで押せます。船の ASCII アートが進んで、数秒後に「成功！」か「失敗！」が、公開メッセージで出ます。
  - **成功（7%）**: 全財産とショップの全品を**置いていき**（自己破産と同じ差し押さえ・貸付は免責・CDS は無効・🔴破産者でブラックリスト）、帝愛の借金が**全額ゼロ**になります（自己破産のように10,000は残らず、種銭も貸されません）。
  - **失敗（93%）**: **罰金**（借金の10%・最低1,000ペリカ）が借金に加わり、**24時間は、もう試せません**。罰金で借金が15,000以上になると、破産猶予に入ることがあります。
  - 破産者は使えません。当たり外れは押した時点で決まります（演出は見せ方だけ）。
- 本番には、すでに借金がある人がいますが、そのまま帝愛の借金として扱います（次の収入から、新しい天引きに変わります）。

## 帝愛銀行・破産猶予・CDS

銀行も保険も、**帝愛**に一本化しています。操作は `/ペリカ 帝愛` の画面だけです。数字は `core/teiai.py` で調整できます。

### 帝愛銀行（預金と取り付け騒ぎ）
- **預金**: 🟢 カタギだけが預けられます（100ペリカ以上）。預金は総資産（ランキング）に数えます。
- **帝愛の胴元の口座**: 銀行の手元（預金の準備）とは**別に**、帝愛が自分のために持つ口座です（サーバーごとに1つ）。**ピンハネ**（借金中の人のデイリーの2割と、地下作業の受け取りの1%）が、全額ここに入ります。残高と、ピンハネの合計は、`/ペリカ 帝愛` の画面に出ます。銀行の預金者の利回りや、取り付け騒ぎの計算には、使われません。
- **部分準備**: 預けられた額の**20%だけ**が手元の現金に残り、残りは「地下融資」に回ります。地下融資は、1時間に2%ずつ現金に戻ってきます。
- **利回り**: ペリカは新しく作りません。次の3つが、預金額に応じて預金者に分配されます（預金者がいなければ、カジノの負け分は、これまでどおり消えるだけです）。
  - **CDS の掛け金**の半分
  - カジノで**プレイヤーが負けた額の3%**
- **利用可能現金** = 手元の現金 − **引当金のロック**。ロックされるのは、破産猶予中の人への CDS の配当見込み（その人の借金の半分まで）と、借金のある人の借金の5%です。
- **取り付け騒ぎ**: 引き出せるのは利用可能現金までで、**早い者勝ち**です。準備率（利用可能現金 ÷ 預金総額）が15%未満なら🟡、5%未満なら🔴、利用可能現金が0以下なら🚨**支払停止（預金封鎖）**で、引き出せません。誰かが破産猶予に入ると、引当金がロックされて準備率が急に下がります。`/ペリカ 帝愛` に、準備率のメーターと猶予中の人の一覧が出ます。
- **AIG ショック**: CDS の配当が手元の現金で足りないときは、**預金者の預金が一律に減らされて**払われます（銀行は、CDS を必ず払います）。
- 借金で強制執行・自己破産になると、預金も、引き出しの制限なしに差し押さえられます（現金の次）。

### 公開される結果
盛り上がる結果は、チャンネルに**公開**されます（誰がやったかも出ます）。失敗や、戦略が見えるものは、本人だけです。
- 公開: **自己破産の結果**（🔴）、**種銭を借りた**（💸）、**他人への CDS**（「💀 ○○ が △△ の破綻に賭けた」。掛け金とオッズも出ます）、**債券の売却**。買い・売り・信用取引・オプションの注文の結果は、もともと公開です。
- 本人だけ: 預金・引き出し、`/ペリカ 帝愛` の画面、**自分への CDS**、`保有`・`市況`、エラー、確認画面。

### 破産猶予（取り立てのカウントダウン）
- 帝愛への借金が **15,000ペリカ以上**になると、**24時間の破産猶予**に入ります。借金を15,000ペリカ未満へ戻せば、猶予から抜けます。
- 時間切れになると、**自動で強制破産**します（1分ごとに確認。内容は自己破産と同じです）。猶予に入ると、結果の画面に一言が出ます。猶予の間は、新しく借りられません（種銭・帝愛の信用）。
- 延滞中の `/貸付` では、猶予に入りません（借金の額だけで決まります）。

### CDS（破綻保証）
- `/ペリカ 帝愛` の「CDS を掛ける」で、**対象を選び**、掛け金（100ペリカ以上）を払います。**オッズ**は、対象の危険度で決まります（カタギ 15倍 → 借金が増えるほど下がり、最低 1.2倍。信用取引の維持率が150%未満だと、さらに下がる）。掛け金は、銀行の収入です。有効期間は**14日**で、強制破産が起きなければ失効し、掛け金は戻りません。
- **自分に掛ける**: 自分が負けて借金に落ちるとき、**まず自分の資産（現物株・債券など）が差し押さえられ、それでもなお足りない分にだけ**、**配当の見込み（掛け金 × オッズ）を上限に、帝愛が借金を肩代わり**します（1件、使い切り）。現金は渡らず、先に自分の資産を失うので、わざと負けても得をしません（チンチロで負けた分を、帝愛に丸投げすることはできません）。**自分への CDS は、配当の見込みの合計が5万ペリカまで**です。
- **他人に掛ける**: その人が**破産猶予の時間切れで強制破産**したとき、または**猶予に入ってから自分で破産**したときに、配当（掛け金 × オッズ）が出ます。
  - **猶予に入る前**に、その人が自分から `/ペリカ 破産` したときは、配当は出ません（結託して、友達に破産してもらう抜け道の対策）。猶予に入ったあとは、ボタン1つで、買われた CDS を無効にはできません。
  - 同じ人に掛けた全員の配当の合計は、その人の**破産時の借金の50%まで**です（超える分は、一律に減らされます）。友達が実際に失った額より、受け取る額が必ず小さくなります。
  - すでに破産猶予に入っている人、破産者には、新しく掛けられません。買い遅れると、オッズが低くなります。
- ショップの「保険券」は、これまでどおり使えます（CDS には統合していません）。

## 貸し借り（ユーザー同士）

`/貸付 提案` で、相手・金額・**日利**・期間を決めて、貸す提案を出します。投稿の「承諾」を**借りる本人**が押すと成立し、お金が移ります（承諾の期限は24時間）。
- **`/貸付 募集`**: 借りたい人が、金額・日利・期間を決めて募集を出します（チャンネルに公開。同時に出せるのは**1件**、期限は24時間、取り下げも可）。投稿の「貸す」を**最初に押した人**が貸し手になり（確認ボタンあり）、その場で貸す人の残高から借りる人へお金が移ります。貸す瞬間に、借りる人が借りられる状態か（破産者でない・延滞中でない）を確かめ直します。
- **信用情報**（提案・募集の画面に出ます）: 借りる人の**身分**、帝愛への借金、破産猶予中か、**返済の実績**（完済・延滞中・破産で免責になった件数）、いま借りている貸付の件数と元本の残り、破産の履歴。**残高・証券・預金の額は見えません**。

- 金額は100ペリカ以上、日利は0%以上（0.1%刻み）で、**どちらも上限はありません**（貸す人の残高が足りること、借りる人が承諾することが歯止めです）。期間は1〜30日です
- **利息は日割りの単利**です。利息 ＝ 元本 × 日利 × 経過日数（貸した時刻から数えて切り上げ、最低1日、期間が上限）。早く返せば、利息は減ります。**期限を過ぎると、遅延損害金**が付きます（元本 × 遅延日利 × 延滞日数（切り上げ）。遅延日利は、約定日利の1.5倍と2.0%の大きいほう。合計は元本の2倍が上限）。延滞しても得になりません。`/貸付 一覧` に、延滞中の遅延損害金が出ます
- 返済は `/貸付 返済`（金額を省くと、残高の範囲で全額）。返済は、まず元本、次に利息に充てます
- 期限が来ると、**借りた人の残高から自動で回収**します。足りない分は**延滞**になり、借りた人の収入の3割の天引きから、帝愛の返済のあとで、古い順に自動で回収します
- 延滞があるとき、破産者のブラックリストの間は、新しく借りられません（帝愛の借金があるだけなら借りられます）。同時に貸せるのは10件まで、承諾待ちの提案は5件までです（借りる件数に上限はありません）。提案の画面には、借りる人の身分と、帝愛への借金が出ます
- 期限の前日と、延滞になったときに、提案を出したチャンネルに知らせます。`/貸付 一覧` で、自分の貸し借りを見られます
- 担保（証券・称号・債券）は、次の段階で足す予定です

## 還元率のレベル（持ち主が変える）

持ち主は、Bot とのDMで `/運営 還元率 設定`（サーバー・ゲーム〔または「すべて」〕・レベル）を使い、ゲームごとの還元率を **1〜6** の6段階で変えられます。**3が標準（いまの設定）**です。`/運営 還元率 一覧` で、いまのレベルと還元率の目安を見られます。

- **勝ったときの勝ち分だけ**を、一定の倍率で増減します。負け・引き分けは変わりません
- 1段階で、還元率が約**4ポイント**動きます（レベル1で約−8、レベル6で約+12）。ゲームごとに倍率を計算するので、どのゲームも同じ幅で動きます（ルーレットは賭け方ごとに計算します）
- 目安: スロット 88%〜108% ／ ルーレット（赤・黒など）89%〜109% ／ パチンコ 約92%〜112% ／ チンチロ 約90%〜110% ／ ブラックジャック 約84%〜104%（ブラックジャックとチンチロは、打ち方で変わる目安です）
- 設定はサーバーごとです。レベル4以上では、還元率が100%を超えるゲームがあり、遊ぶだけでペリカが増えます
- ユーザーには、レベルは見せません

## 競馬（4時間おき・1日4回のレース）

ショップで「**競走馬（購入券）**」（30,000ペリカ）を買い、`/競馬 厩舎` で名前・毛色・勝負服の色を決めて馬を迎えます（1人3頭まで）。馬をレースに申し込んで走らせたり、レースに馬券を買って賭けたりできます。

- **開催**: **9・13・17・21時（日本時間）の1日4回**、定時レース。9時から0時までの間に、4時間おきです。1回は4時間の周期です。**発走の2時間前に出走の申し込みが始まり、1時間前に締め切り**、帝愛の馬で8頭まで埋めて、**出馬表とオッズ**が出ます。そのあと発走、結果、次の申し込みの開始まで2時間あきます（最初のレースの申し込みは、朝7時に始まります）。馬券は**発走の2分前**まで買えます。持ち主は `/運営 競馬開催` で臨時レースも開けます（申し込み分・発売分・掲示するチャンネルを指定）。買った馬券は、レースのチャンネルに公開されます。締切後の古い掲示は「締め切りました」に書き換わります。
- **ステータス**: スピード・スタミナ・パワー・根性の4つで、**合計は200**（各20〜80。買った直後は全部50）。ショップの「**にんじん**」（1,000ペリカ）1本で、5点を別のステータスへ動かせます。「**金にんじん**」（50,000ペリカ）は、1本で**合計が10点増え**、5点ずつ好きな2か所（同じ所でもよい）に振れます（振り分けを決めて「使う」を押すまで反映しません。1頭に1本まで）。根性は**ラストスパート**（残り4分の1で、最大約5%の加速）に効きます。
  - コースは、距離（1,000・1,200・1,600・1,800・2,000・2,400・3,000m）と馬場（良・稍重・重・不良）が毎回変わります。短距離はスピード、長距離はスタミナ、重い馬場はパワー、ラストスパートは根性が効きます。毎回の調子（◎○△）も、出馬表に出ます。
- **引退**: `/競馬 厩舎` の「🎌 引退させる」で、馬を引退させます。**戦績に応じて引退金**がもらえます（1勝ごと 8,000、3着以内（勝ちを除く）1回ごと 3,000。上限 100,000）。**3着に入れなかった分は引退費用**（1回ごと 1,500。上限 20,000）として引かれ、全体がマイナスなら**払います**（払えないときは引退できません）。出走予定のレースが終わるまでは引退できず、引退した馬は戻りません。
- **申し込み**: 出走料 1,000ペリカ。1人1レースに1頭まで。締切までは取り下げられます（出走料は返ります）。馬は、出走予定のうちは、ほかの**定時**レースに出せません（同時に出られる定時レースは1つだけ）。**臨時レースは別で**、出走予定の馬も出せます（臨時どうし、臨時と定時を重ねて出せます）。**賞金**は、1着 12,000・2着 5,000・3着 2,000ペリカ（馬主へ。収入なので、借金中は天引きされます）。
- **馬券**（6種類）: **単勝**（1着）・**複勝**（3着以内）・**馬連**（1・2着の2頭、順不同）・**ワイド**（3着以内に入る2頭、順不同）・**馬単**（1着と2着、順番どおり）・**三連複**（1〜3着の3頭、順不同）。**単勝・複勝は、何頭でもまとめて選べます**（選んだ頭ごとに、同じ金額ずつ、別々の馬券になります。1つのレースの合計の上限は、これまで通りです）。オッズは**戦績**（出走数・勝ち数・3着以内の数）で決まります。出走が少ない馬は平均に寄せ（4戦ぶんの平均的な成績を足して薄める）、**初出走は確率を0.75倍に見積もって、オッズが高く**なり、**調子**（◎×1.15・△×0.85）でも動きます。**ステータスはオッズに入りません**（レースの結果は、ステータスで決まります。戦績と強さのずれが、狙い目になります）。帝愛の馬には、強さと関係ない作りものの戦績がつきます。組み合わせの馬券は、勝つ確率から着順の確率を計算します（**控除は単勝・複勝15%、組み合わせの馬券20%**。最高100倍）。**賭けた時点のオッズで確定**します。1回100〜10,000ペリカ、1レース合計30,000ペリカまで。胴元は帝愛で、ほかのカジノと同じく、負けた額の3%が預金者の利回りになります。
- **発走**: 結果は発走の時点で決まり、先に精算します。そのあと、約18秒のアニメーション（実況つき）と、結果・払い戻し・賞金が、お知らせのチャンネルに出ます。Bot が止まっていて時刻を過ぎたときは、起動後にすぐ走らせます。
- **破産すると、持ち馬は差し押さえられます**（購入券の値段の50%で換金）。差し押さえた馬は、帝愛の競売に出ます（ショップ画面の「🕴️ 帝愛の競売」。定価の90%から1日10%ずつ下がり、70%で止まる。名前とステータスはそのまま。買えるのはカタギだけで、馬は3頭まで）。申し込み中の馬は取り下げ、すでに出走が決まっていた馬は帝愛の馬に替わります（賞金は破産した馬主に入りません）。
- 馬の名前に、メンション・リンク・装飾の文字（@ < > ` * _ ~ | # : /）は使えません。数字は `core/horse.py` で調整できます。

## 取引（プレイヤー間の市場と競り）
`/取引` で、**競走馬**と、**消耗品・見た目の品**（カードの色とアイコン・演出・名前の色）を、プレイヤー同士で売り買いできます。**称号・コレクション・限定品・帝愛市の品は、売れません。**

- **出品**（`/取引 出品`）: 品・馬を選び、**方式**（定価 / 競り）と**値段**を決めます。出した品・馬は、出品の間、**預かります**（馬は厩舎から出て、レースにも出られません。出品中の馬も、持てる3頭に数えます）。1人、同時に**5件**まで。出走予定の馬は、出品できません。装備中の品は、出品すると外れます。
- **定価**: 出した値段で、買う人がすぐ買えます。有効期間は**7日**で、売れ残ると品が戻ります。
- **競り**: 長さは**1・6・24・72時間**。入札は、いまの最高値より**5%（最低100）以上**高く入れます。**入札のお金は、残高から預かり**、抜かれたら返ります。**締切の5分前を切ってからの入札は、締切が5分延びます**（ぎりぎりの入札だけで決まらないように）。締切に、最高値の人が落札します（**落札は、告知チャンネルに知らせます**）。入札が入った競りは、取り消せません。入札が1つもなければ、売れ残りとして、品が戻ります。
- **買う・入札**（`/取引 一覧` → 出品を選ぶ → 「買う」「入札する」）: **借金も延滞もないカタギだけ**です。持っているもの（見た目の品）や、持てる数（馬は3頭）を超えるものは、買えません。1万ペリカ以上は、確認ボタンが出ます。
- **手数料**: 売れたとき、売り手の受け取りから**5%**を引きます（帝愛銀行の収入）。
- **送金の抜け道をふさぐ決まり**: (1) 値段は、**定価の幅**に収まる必要があります（品は定価の**10%〜500%**、馬は**3,000〜300,000ペリカ**）。(2) **同じ2人（売り手と買い手）の取引は、24時間で合計10万ペリカまで**です（どちらが売り手でも、合わせて数えます）。
- 売れた・落札した・抜かれた・売れ残った、は、次にゲームを遊んだときの一言で伝わります。
- `/取引 自分` で自分の出品と入札中の競りを、`/取引 取消` で自分の出品の取り消しができます。

## 地下作業（ペリカが尽きた人の救済）

`/地下 作業` で、作業場が開きます（チャンネルに公開されて、みんなに見えます。押せるのは、開いた本人だけです）。元手は 0 で、借金中でも、手元が 0 でも始められます（まず、その場でボタンを押して元手を作ります）。

- **働く**: 1回押すごとに、稼ぎが貯まります（工具なしで 10 ペリカ）。押せるのは、最短 **1秒おき**です。
- **疲労**: 押すたびに溜まり、溜まるほど稼ぎが減ります（満タンで 20%）。時間で自然に回復します（満タンから約17分）。ショップの**栄養ドリンコ**（300ペリカの消耗品。**在庫は1人ずつ別々**で、10本まで・30分に1本ずつ補充されます）を、画面の「🥤 栄養ドリンコ」で飲むと、疲労が60すぐ回復します（疲れていないときは減りません）。
- 押しても、事故は起きません。押すたびに、必ず稼げます。
- **工具の強化**（稼いだペリカで、各5段まで。150 / 400 / 900 / 1,800 / 3,500）: ⛏ツルハシ（稼ぎ +4 ずつ。最大 30）、🧤手袋（疲労の溜まりが 3.0 → 1.0）。
- **受け取り**: 稼ぎは「未受け取り」に貯まり、「💰 受け取る」で、**まとめて**手元に移ります（押した分も、作業員の稼ぎも、同じ受け取りに入ります）。作業員を雇っているときは、「未受け取り」の下に **（うち作業員 ◯◯ペリカ）** と、そのうち作業員が稼いだ分（基本給と鉱石の売値）が出ます。**受け取るとき、1%がピンハネされます**（借金の有無に関わらず、全員。画面には「慈善団体に寄付されます」と出ます。ピンハネ分は、**帝愛の胴元の口座**に入ります）。手元に入った残りに、借金があれば、さらに収入の3割の天引きがかかります。収入なので、借金があれば、ほかと同じく天引きされます。
- **制限はありません**: 1日の上限も、手元の多さによる制限もありません（疲労で稼ぎが減るので、連打を続けるほど効率は落ち、押す手間もかかります。画面には「今日の稼ぎ」が出ます）。稼ぎが多すぎると感じたら、`core/labor.py` の数字を下げます。
- **採掘ランキング**: `/地下 ランキング` で、稼いだペリカの多い順（通算 / 今日）を、チャンネルに公開します。作業員の稼ぎも数えます。同額なら、押した回数が少ない人が上です。自分が10位より下のときは、自分の順位も出ます。
- **雇用（放置で働き、鉱石を掘る）**: 「👷 作業員」のタブで、稼いだペリカで**作業員**を雇います。作業員は、ボタンを押さなくても、時間がたつだけで働きます（受け取らずに数えるのは、最大24時間分。毎日1回見に来れば、ちょうど1日ぶんまるごとです）。
  - 作業員は、**7日間の契約**で雇います。**契約料**（雇うとき・更新のときに払う）は、🧒**見習い**340、👷**坑夫**1,200、🧑‍🔧**職人**2,700、🕴️**監督**1,500。同じ種類を何人雇っても、契約料は同じです。
  - **基本給と鉱石**: 作業員は、基本給（1時間に 見習い0.6・坑夫3.35・職人7.85）をもらい、**働いた1時間ごとに鉱石を1回掘ります**。基本給は契約料の約5割しかなく、**基本給だけでは赤字**です。⚫**石炭**（売値1。**働いた1時間の約4割で、どの作業員も掘れる**）・🟤**銅**（売値20）・⚪**銀**（80）・🟡**金**（400）・💎**ダイヤ**（3,000）・🌟**伝説の鉱石**（30,000）が出ると、その売値が稼ぎに入ります（外れもあります）。
  - **平均は赤字**: 毎日受け取る人の1週間で、基本給と鉱石を合わせた期待値は、契約料の約85〜90%です。4週間で黒字になるのは、約1〜3割で、**運よくレア鉱石を引いた人だけが、大きく黒字**になります。上位の作業員ほど、レアが出やすくなります。
  - 🕴️**監督**: 自分では掘らず、全員のレア鉱石の出やすさを +25% にします（人数に上限はありません）。基本給は増えません。
  - 掘った鉱石は、「未受け取り」に入り、画面の「💎 作業員の掘り出し」に出ます。「受け取る」で、売値が手元に移ります。**ダイヤ以上を受け取ったときは、チャンネルに公開で知らせます。**
  - 画面の「📜 最近の掘り出し」に、**いつ・どの作業員が・何を掘ったか**が、新しい順に出ます（石炭は除く。直近40件を残します）。抽選は、画面を操作したときにまとめて行われるので、時刻は、働いた時間のあいだの1時間ごとの枠にそろえて出します。
  - 🔁**自動更新**（最初はオン）: 契約が切れたら、貯まっている稼ぎから契約料を払って更新します（足りなければ手元から）。それでも払えない・オフにしているときは、その作業員は退職します。久しぶりに見に来ても、切れていた期間の契約料は取られず、更新は1回分です。
  - 人数は、最初は **5人**まで。🏠**寮**を強化すると +1人ずつ（2,000 / 6,000 / 15,000 / 40,000 / 100,000。最大10人）。枠が埋まったら、契約の早く切れる人から**解雇**（契約料は戻りません）して、強い人に替えます。
  - 💼**賃金**: 「標準」と「低賃金」。低賃金は、基本給が **×1.2** になる代わりに、作業員が1日に **5%** の確率で、1人ずつ辞めます（鉱石は変わりません。低賃金でも、平均は契約料に届きません）。
  - 稼ぎは、ほかの収入と同じく、借金があれば天引きされます（破産しても、作業員は差し押さえません）。
  - 数字は、シミュレーションで確かめて決めています。`core/labor.py` の基本給（`WORKER_RATE`）・鉱石の表（`ORES`・`ORE_POWER`）・契約料（`CONTRACT_FEE`）で調整できます。
- 数字は `core/labor.py` で調整できます。

## パチンコ（打ち出し型）

実機に近づけた作りです。**1セット = 100発**を打ち出し、賭け金がそのセットの代金です。

- 玉は1発ごとに、約**7%**がスタートに入ります（平均7回転/セット）。**入らない玉は、釘やハズレの穴に落ちます**。1回も入らないセットもあります
- 入った数だけ回転します。回転ごとに、予告の色（青<赤<金）とリーチの格（ノーマル<スーパー<プレミアム）が出て、**出るほど当たりやすく**なります。リーチなしで突然揃う「サプライズ当たり」もあります
- 当たると**大当たり**。出玉は賭け金の**2倍（69.5%）・10倍（26.5%）・30倍（4%）**のどれかで、**確変の連チャンが50%で続きます**（平均2連）。1セットの払い戻しは、出玉の合計です（**上限はありません**）
- 当たるセットは約**9%**。還元率は100%を超えないよう調整してあります
- **`回数`（1〜10）**で、同じ賭け金のセットを続けて打てます。賭け金 × 回数 が、そのまま賭け金になります（残高が足りないと始まりません）。結果の下の「🎰 ×5連続」（5セットのあとは「×10連続」）のボタンでも続けられます。連続して打っても、**1回の遊び**として数えます（ミッション・連勝・週間ランキングは1回分）
- 結果は賭けた時点で決まり、先に精算します。**当たった回転だけ**を、実機のように見せます。リールは「回っている／止まっている」の状態を持ち、左右が同じ絵柄で止まると**リーチ**、そのあと出目が決まるまで左右は変わりません（変わるのは、再回転する擬似連・全回転のときだけ）。**3つ揃うのは最後の1コマだけ**で、揃ったら演出は終わり、すぐ当たりの宣言になります。演出は、格（リーチなし・ノーマル・スーパー・プレミアム）ごとの台本から**1本を選んで**流し、予告・擬似連（0〜4回）・カットイン・発展の種類は回ごとに変わります（全部が毎回流れるわけではありません）。当たりの宣言と連チャンの演出（当たりの宣言と連チャン連チャン数の大表示・5連や10連の節目・終了のまとめ）は、演出が終わったあとに出します（ハズレの回転は「〇回転 経過」のように数字でまとめ、外れたリーチは文字で触れるだけです）。リーチの当たりでは、**復活演出**が出ることがあります（いったん3つ目がずれて「外れた」ように見せて、「それでも!!!」「と、思っていたのか」などの台詞のあと、再回転して揃います。リーチがノーマルで10%・スーパーで25%・プレミアムで30%。当たったときだけで、ハズレの回転には出ません。当落は演出より先に決まっていて、変わりません）。当たりが複数あっても省略せず、約60コマ（約66秒）分の上限まで順に見せ、超えた分は数でまとめます。連続投入でも、当たったセットを出玉の大きい順に、上限まで見せます
- 持ち主向けの `/運営 還元率` のレベルは、セットごとに勝ち分へかかります

## サーバーの承認（友達のサーバーだけで遊ぶ）
`config.json` に `"require_approval": true` と、自分のユーザーIDを入れた `owner_ids` を設定すると、**Bot が新しいサーバーに追加されたとき、持ち主に DM で通知が届きます**。

1. 友達が招待 URL から Bot を追加します。
2. 持ち主に DM が届きます（サーバー名・ID・持ち主・メンバー数つき）。ボタンは **【許可する】** と **【断って退出させる】** です。
3. 【許可する】を押すと、そのサーバーIDが記録に保存され、**再起動なしですぐ**遊べるようになります（サーバー側にも通知します）。
4. 承認前のサーバーでコマンドを使うと「承認待ちです」と表示され、持ち主にもう一度（1時間以上あけて）通知されます。

- **持ち主のコマンド**（`/運営`）: **Bot とのDMでだけ**使えます（サーバーのコマンド候補には出ません）。`/運営 サーバー一覧`（許可・承認待ち・断った一覧）、`/運営 サーバー許可 サーバーid`（IDを指定して許可。まだ参加していないサーバーを先に許可しておくこともできます）、`/運営 サーバー取消 サーバーid`（許可を取り消して、Bot を退出させる）。設定ファイル（`allowed_guild_ids`）で許可したサーバーは取り消せません。
- 持ち主は、承認待ちのサーバーの中でもコマンドを使えます（そこから許可を出せます）。
- DM を受け取れない設定の場合は、Bot とのDMで `/運営 サーバー一覧` を使って承認待ちを確認し、`/運営 サーバー許可` で許可してください。
- ボタンは Bot を再起動しても動きます。一度断ったサーバーは、追加し直すと、もう一度確認が届きます。

## ランキング掲示板（自動で更新）
`/ペリカ ランキング掲示 チャンネル:#ランキング` を一度実行すると、Bot がそのチャンネルにこのサーバーのランキング（上位10人）を投稿します。以降は **同じメッセージを1分ごとに書き換える** ので、新しい投稿は増えません。

- 設定できるのは「サーバー管理」権限を持つ人と Bot の持ち主（`owner_ids`）で、**1サーバーに1つ**です。もう一度実行すると、前の掲示板を削除して新しく置き直します。
- メッセージが消されても、次の更新で自動的に投稿し直します。チャンネルが消えたら、掲示は自動で止まります。
- 止めるときは `/ペリカ ランキング掲示` で「止める」を True にします（投稿も削除します）。Bot が再起動しても、掲示は続きます。
- Discord の仕様上、Bot が編集できるのは **Bot 自身が投稿したメッセージだけ** です（人が貼ったメッセージは編集できません）。
- 載るのは、そのサーバーで遊んだ・コマンドを使った人だけです。

- **在庫（買える数）**: 買い占めを防ぐため、品によっては**在庫**があります（いまは、栄養ドリンコ）。在庫は**1人ずつ別々**で、買うと減り、時間がたつと補充されます（上限まで）。売り場の画面に、自分の在庫と、次の補充の時刻が出ます。在庫を超える個数は、買えません。

- `/ショップ` だけで、**操作パネル**（自分だけに見える）が開きます。上のボタンで**売り場**を選びます（🏠トップ・🏷️称号・🎴カード・🎟️消耗品・🐎競馬・🕴️帝愛市・✨演出・名前の色・🏆コレクション）。品の名前の前には、合う絵文字が付きます（画面の表示だけで、ニックネームなどに出る名前は変わりません）。各売り場は、**値段の安い順**に並び、持っている品に ✅ が付き、称号とコレクションは値段の段階（🌱入門・🥉中堅・🥈大物・🥇頂点）で分かれます。下の選択肢で買います（消耗品は個数も選べます）。「🎒 持ち物」の画面で、身につける・使う・外す、称号をニックネームの後ろに付ける、ができます。
- 称号・カード・名前の色は一度買えばずっと使えます（消耗品は使うとなくなります）。
- 10,000ペリカ以上の買い物は確認ボタンが出ます。景品は人に渡せません。
- **ゲームの途中は、買い物も消耗品の使用もできません**（結果を見てから保険券を使う、などを防ぐため）。
- 保険券は、勝ちや引き分けでは使われず、**負けたとき**に1枚使われます。戻る額は券の値段より少ない（最大1,000ペリカ）ので、買って使うだけで増えることはありません。チンチロの倍払いの追加分は対象外です。
- **🕴️ 帝愛の競売**（ショップ画面の下のボタン）: 破産で差し押さえた品（消耗品・カードの色とアイコン・演出・名前の色）が、売りに出ます。**称号**・コレクション・限定称号は出ません（称号は、差し押さえたら、そのまま没収されます）。値段は定価の**90%**から、**1日ごとに10%**ずつ下がり、**70%**で止まります（70%より下がらないので、**売れ残る品があっても、そのまま棚に残ります**）（差し押さえの換金率50%より高いので、買い直して破産し直すと損をします）。買えるのは**カタギだけ**で、持っているもの（消耗品以外）は買えません。売上は、帝愛銀行の収入（預金者の利回り）になります。
- 買い物・送金は、確認ボタンの待ち時間も含めて「プレイ中」として扱い、その間はゲームを始められません。

### 称号をニックネームに付ける
「🎒 持ち物」の画面で「称号を名前の後ろに付ける」を押すと、装備中の称号が **ニックネームの後ろ** に付きます（例: `たつ【ざわ…ざわ…】`）。メッセージの名前の横に表示されます。

- **自分で選んだ人だけ**、そのサーバーでだけ有効です（初期は付けません）。「称号を名前に付けない」で、元のニックネームに戻ります。
- 称号を付け替えたり外したりすると、ニックネームも自動で変わります。ONにしている複数のサーバーにも反映されます。
- Bot に **「ニックネームの管理」権限** が必要です。**サーバーの持ち主と、Bot のロールより上のロールの人は、Discord の仕様で変えられません**（その場合は理由を案内して、設定は有効になりません）。
- ニックネームは32文字までなので、長い名前の人は、称号を残して名前の後ろが切れて付きます。**付ける前のニックネームは記録しているので、称号を外すと、切れる前の名前に完全に戻ります。**
- 自分でニックネームを変えると、称号が消えることがあります。もう一度「🎒 持ち物」の画面で付け直せます。自分で付けた `【…】` は消しません（ショップの称号と同じ名前のものだけを外します）。
- 一度も ON にしていない人のニックネームには、Bot は触りません。Bot がサーバーから外れると、そのサーバーの設定は消えます。

### 名前の色（ロール）について
- Bot が「ペリカ・赤」のようなロールを作って付けます。**権限は一切持たない、色だけのロール**です。同じ名前で権限を持つロールがすでにあるサーバーでは、安全のため使わず、名前を変えるよう案内します。Bot が付け外しするのは、この色ロールだけです。
- Bot に **「ロールの管理」権限** が必要です。招待URLの権限は `permissions=402738176` にしてください（すでに招待済みなら、そのURLをもう一度開いて承認すると権限が追加されます）。
- サーバーの名前の色は、**ロール一覧で一番上にある「色つきのロール」の色** になります（色が「デフォルト」のロールは無視されます）。
  色ロールは Bot のロールのすぐ下に置くので、それより上にある運営用ロールなどの色は優先されます。
  すでにある別のロール（例: シークレットチャンネル用）に色が付いていて、それが色ロールより上にある場合は、そちらの色が優先されます。色ロールを優先させたいときは、そのロールの色を「デフォルト」にするか、色ロールより下に動かしてください。
- Bot のロールは、色ロールを動かせるように、サーバー設定のロール一覧で十分上（運営用ロールの直下など）に置いてください。

## 導入手順

### 1. Discord 側の準備
1. [Discord Developer Portal](https://discord.com/developers/applications) で **「新しいアプリケーション」** を作ります。
2. **「Bot」** を開き、**「トークンをリセット」** でトークンをコピーします（一度しか表示されません。他人に見せないでください）。
3. **特権インテントは不要です**（メッセージの内容もメンバー一覧も読みません）。

### 2. 設定と起動

**uv を使う場合（推奨）:**
```bash
uv sync
cp config.example.json config.json      # Windows: copy config.example.json config.json
uv run main.py
```

**pip / venv を使う場合:**
```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
cp config.example.json config.json      # Windows: copy config.example.json config.json
.venv/bin/python main.py                # Windows: .venv\Scripts\python main.py
```
`config.json` を編集します。

| 項目 | 説明 |
|---|---|
| `token` | Bot トークン（必須） |
| `allowed_guild_ids` | あらかじめ許可するサーバーのID一覧。`require_approval` が false のときは、空 `[]` ならどのサーバーでも遊べ、空でなければこの中だけ遊べます |
| `require_approval` | `true` にすると**承認制**になります。許可リスト以外のサーバーは、持ち主が承認するまで使えません（下の「サーバーの承認」参照）。初期は `false` |
| `legacy_guild_id` | サーバーごとに分ける前の古い記録がある場合に、それを引き継ぐサーバーのID。省略すると `allowed_guild_ids` の先頭を使います。古い記録がないとき（新規）は不要です |
| `owner_ids` | Bot の持ち主のユーザーID。サーバーの承認の通知（DM）が届き、`/運営` のコマンドを使える人です（複数可） |
| `test_guild_id` | 開発用。指定するとそのサーバーだけにコマンドが即時反映されます。**本番では `null`**（別の場所の Bot が登録したコマンドと重複して、同じコマンドが2つ表示されます） |
| `utc_offset_hours` | デイリーの切り替わる時刻とミッションの日付の境目の時差。日本は `9`（日本時間の0・6・12・18時にデイリーが、0時にミッションが切り替わります） |

サーバーID・ユーザーIDは、Discord の「設定 → 詳細設定 → 開発者モード」をオンにして、右クリックの「IDをコピー」で取れます。

### 3. サーバーへ招待
`CLIENT_ID` を、Developer Portal の「一般情報」にあるアプリケーションIDに置き換えて開きます。

```
https://discord.com/oauth2/authorize?client_id=CLIENT_ID&scope=bot+applications.commands&permissions=402738176
```
必要な権限は「チャンネルを見る」「メッセージを送信」「埋め込みリンク」と、ショップ用の「ロールの管理」（名前の色）・「ニックネームの管理」（称号の表示）、`/運営 発言削除` 用の「メッセージ履歴を読む」です。ショップと発言削除を使わないなら `permissions=19456` で足ります。

## 仕組みと安全
- **賭け金は開始時に預かり**、結果が決まったら精算します（スロット・パチンコなどは、演出の前に精算するので、演出の途中でメッセージを消しても結果は変わりません）。残高の増減は1回の処理で行い、台帳（履歴）に記録します。
- 連打や同時操作でペリカが増減しないよう、同じ人は同時に1つのゲームしか始められません。
- **Bot が途中で止まった場合、預かっていた賭け金は次の起動時に全額返ります。**
- ボタンは賭けた本人だけが押せます。放置すると、チンチロは「目なし」、ブラックジャックは「スタンド」として自動で精算します。
- 保存するデータ: サーバーごとの、ユーザーID・残高・成績・増減の履歴・持ち物。メッセージの内容は読みません。保存先は `data/casino.db` です。

## 運用
- 常時動かす場合は、`systemd` などで自動起動・自動再起動にします（管理補助bot と同じ要領）。**同じトークンで2か所から起動しないでください。**
- データのバックアップは、Bot を止めてから `data/` をコピーします。
- トークンを漏らしたら、すぐ Developer Portal で再発行して `config.json` を差し替えてください。`config.json` と `data/` は `.gitignore` 済みです。

## 持ち主向けの管理（Bot とのDMで操作します）
管理者用のコマンドは、**Bot とのDM**だけに出る `/運営` にまとめてあります（サーバー内のコマンド候補には出ません）。説明が `[管理者]` で始まり、使えるのは **Bot の持ち主（`owner_ids`）だけ**です。ほかの人がDMで使っても「権限がありません」と返ります。サーバーが必要なコマンドでは、`サーバー` の欄に、Bot が参加しているサーバー名の候補が出ます。

**告知を出す先（サーバーとチャンネル）を指定できます。** `お知らせ`・`抽選 開催`・`抽選 再掲示`・`イベント 開始`・`クイズ 追加`・`クイズ 一括追加` には `チャンネル` の欄があり、先に `サーバー` を選ぶと、そのサーバーで **Bot が投稿できるチャンネル**（見る・送る・埋め込みリンクの権限がある所）の候補が出ます。省略すると、これまでどおり告知チャンネル（ランキング掲示のチャンネル、無ければシステムチャンネル）です。`チャンネル` だけを選ぶことはできません（`サーバー` も必要）。特別イベントは、終了の告知も開始と同じチャンネルに出ます。

| コマンド | 内容 |
|---|---|
| `/運営 競馬開催` | サーバーと、申し込み分・発売分（分。省略で5分ずつ）・チャンネル（省略で告知チャンネル）を指定して、**臨時の競馬レース**を開きます（申し込み → 馬券の発売 → 2分後に発走）。定時レースとは別に開けます |
| `/運営 残高設定` | サーバーと相手、金額（-1,000,000,000〜1,000,000,000）を指定して、**残高をその額ちょうどにします**（**マイナス（例 `-5000`）なら、手元を0にして、帝愛の借金をその額ちょうどにします**。いまの借金は置き換わります。0以上なら、借金には触れません。増やすことも減らすこともできます。差額は台帳に残ります。証券・預金は変えません）。理由は台帳に残せます |
| `/運営 付与` | サーバーと相手（名前の候補が出なければユーザーID、`<@…>` の形も可）、金額（1〜10,000,000）、理由を指定してペリカを付与します。相手がそのサーバーにいなければ付与しません |
| `/運営 発言削除` | `サーバー` と `チャンネル` を選ぶと、そのチャンネルにある **Bot 自身の発言を、すべて消します**（他の人の発言には触れません）。**確認のボタンを押すまで消さず、元に戻せません。** ランキング掲示板・チャートの自動更新・クイズや貸付や抽選の投稿（ボタン付き）も消えます。自分の発言は1件ずつしか消せないので、多いと数分かかります。Bot に「メッセージ履歴を読む」権限が要ります（なければ、案内が出て何も消しません）。15分を過ぎて画面が更新できなくなったときは、結果が DM に届きます |
| `/運営 お知らせ` | 指定した文字（改行できます）と画像を、Bot がお知らせとして告知チャンネルに出します。`サーバー` を空にすると、許可されている全サーバーに送ります。`見出し`（空なら「📢 お知らせ」）と `画像`（8MBまでの画像）は任意です。**送る前にプレビューが出て、「送信する」を押すまで送りません**。通知（メンション）は飛びません |
| `/運営 イベント 開始` `終了` | 好きなタイミングで**特別イベント**を開きます（突発イベントと同じ「勝ち分の上乗せ」）。`ゲーム`・`時間`（1〜180分、省略で30分）・`上乗せ率`（1〜300％、省略で50）・`サーバー`（空なら許可されている全サーバー）を指定します。開始と終了は告知チャンネルに出ます。定例の突発イベントとは**重ならず、大きいほうだけ**かかります。1回の上乗せの上限（10,000ペリカ）は同じです。開催中に新しく開くと置き換わり、`終了` ですぐ終わらせられます |
| `/運営 パチンコ統計` | パチンコの当たり率・スタート入賞・還元率・最大連チャンを、設計した数字（予告の色・リーチの格ごとも）と実際の記録で並べて見ます。`サーバー`・`日数` で絞れます。回転数が少ないうちは「参考」と出ます。数字の調整は `games/pachinko.py` の表で行います |
| `/運営 クリック履歴` | 地下作業の「働く」を押した記録を、1時間ごとに見ます（`サーバー`・`ユーザー`・`時間`〈1〜336。省略で24〉）。押した回数・稼ぎ・休まず押し続けた最長の時間・間隔の平均と**ばらつき**（人間が手で押すと、ふつう0.3以上。0.1未満で100回以上の時間に ⚠️）が出ます。自動操作の疑いを、持ち主が確かめるためのもので、何かを自動で制限はしません。記録は14日残ります |
| `/運営 還元率 設定` `一覧` | ゲームごとの還元率レベル（1〜6）の変更。詳しくは「還元率のレベル」の節 |
| `/運営 抽選 開催` `再掲示` `中止` | 指定したサーバーの**告知チャンネル**（ランキング掲示のチャンネル、無ければシステムチャンネル）に、抽選の募集を出す・出し直す・中止して返金する |
| `/運営 クイズ 追加` `一覧` `削除` | クイズの登録（入力フォームが開く）・一覧・削除 |
| `/運営 サーバー一覧` `サーバー許可` `サーバー取消` | Bot を使えるサーバーの管理 |
| `/ペリカ ランキング掲示` | ランキング掲示板の設置。サーバー内で、サーバー管理の権限を持つ人も使えます |

サーバーの端末から行う `manage.py` も、そのまま使えます（Bot の起動中でも安全です）。

```bash
uv run manage.py grant サーバーID ユーザーID 金額 [理由]   # ペリカを付与（1〜10,000,000）
uv run manage.py servers                               # サーバーの許可状況
```
※ pip / venv 環境の場合は `uv run` を `.venv/bin/python` に置き換えてください。
