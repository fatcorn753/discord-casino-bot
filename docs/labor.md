## 地下作業（ペリカが尽きた人の救済）

`/地下 作業` で、作業場が開きます（チャンネルに公開されて、みんなに見えます。押せるのは、開いた本人だけです。**1人1枚まで**で、`/地下 作業` をもう一度開くと、前に開いた作業場は消えます）。元手は 0 で、借金中でも、手元が 0 でも始められます（まず、その場でボタンを押して元手を作ります）。

- **働く**: 1回押すごとに、稼ぎが貯まります（工具なしで 10 ペリカ）。押せるのは、最短 **1秒おき**です。
- **疲労**: 押すたびに溜まり、溜まるほど稼ぎが減ります（満タンで 20%）。時間で自然に回復します（満タンから約17分）。ショップの**栄養ドリンコ**（300ペリカの消耗品。**在庫は1人ずつ別々**で、10本まで・30分に1本ずつ補充されます）を、画面の「🥤 栄養ドリンコ」で飲むと、疲労が60すぐ回復します（疲れていないときは減りません）。
- 押しても、事故は起きません。押すたびに、必ず稼げます。
- **「働く」の1日の上限**: 「働く」は、**1日 1,000回まで**押せます（日付は日本時間の0時で替わります）。回数で区切るので、ツルハシを強化するほど、1日に稼げる額もそのまま増えます。上限に達すると、**1回 1 ペリカ**しか稼げません。作業員の稼ぎ・鉱石・発掘品は、上限の対象外です。画面の「📅 今日の稼ぎ」に「◯◯（クリック ◯◯/1,000回）」の形で出ます。
- 💥**鉱脈ヒット**: 「働く」を押すたびに、確率で**稼ぎが5倍**になります。確率はツルハシのレベル（+1%/Lv）と、雇用中の作業員の数（+0.2%/人）で上がり、最大30%です。まれに（15%）、さらに鉱石（石炭・銅・銀・金のどれか）も手掘りで見つかります。上限に達した日は起きません。画面に、いまの鉱脈ヒット率が出ます。
- 🔥**作業コンボ**: 「働く」を**10回押すごとに、その1回の稼ぎが+20%**になります（鉱脈ヒットと重なることもあります）。
- 🪨**今日の地層**: 日替わりで、サーバー共通の地下コンディションが1つ決まります（鉱脈ヒット率+5%／疲労の溜まりが20%軽い／手掘りの銀が2倍出やすい／特になし、のどれか）。画面の下に出ます。
- **自動操作の疑いがあるときの、早めの打ち止め**: 1時間に100回以上押して、押す間隔のばらつきが小さい（標準偏差 ÷ 平均が0.1未満。機械的に規則正しい）状態が、**3時間連続**すると、その日はそこで打ち止めになります（1回1ペリカ）。BAN ではなく、翌日には戻ります。運営は `/運営 クリック履歴` で、同じ基準の記録を確認できます。
- **工具の強化**（稼いだペリカで、各10段まで。150 / 400 / 900 / 1,800 / 3,500 / 7,000 / 14,000 / 28,000 / 56,000 / 112,000）: ⛏ツルハシ（稼ぎ +4 ずつ。最大 50）、🧤手袋（疲労の溜まりが Lv5 まで 0.4 ずつ減って 3.0 → 1.0、Lv6 以降は 0.1 ずつ減って、Lv10 で 0.5）。
- **受け取り**: 稼ぎは「未受け取り」に貯まり、「💰 受け取る」で、**まとめて**手元に移ります（押した分も、作業員の稼ぎも、同じ受け取りに入ります）。作業員を雇っているときは、「未受け取り」の下に **（うち作業員 ◯◯ペリカ）** と、そのうち作業員が稼いだ分（作業員の稼ぎと鉱石の売値）が出ます。**受け取るとき、3%がピンハネされます**（借金の有無に関わらず、全員。画面には「ピンハネされた ◯◯ ペリカは、慈善団体に寄付されます」と出ます。ピンハネ分は、**帝愛の胴元の口座**に入ります）。手元に入った残りに、借金があれば、さらに収入の3割の天引きがかかります。収入なので、借金があれば、ほかと同じく天引きされます。
- **制限はありません**: 1日の上限も、手元の多さによる制限もありません（疲労で稼ぎが減るので、連打を続けるほど効率は落ち、押す手間もかかります。画面には「今日の稼ぎ」が出ます）。稼ぎが多すぎると感じたら、`core/labor.py` の数字を下げます。
- **採掘ランキング**: `/地下 ランキング` で、稼いだペリカの多い順（通算 / 今日）を、チャンネルに公開します。作業員の稼ぎも数えます。同額なら、押した回数が少ない人が上です。自分が10位より下のときは、自分の順位も出ます。
- **雇用（放置で働き、鉱石を掘る）**: 「👷 作業員」のタブで、稼いだペリカで**作業員**を雇います。作業員は、ボタンを押さなくても、時間がたつだけで働きます（受け取らずに数えるのは、最大24時間分。毎日1回見に来れば、ちょうど1日ぶんまるごとです）。
  - 作業員は、**1日（24時間）の契約**で雇います（結果が1日で分かります）。**契約料**（雇うとき・更新のときに払う）は、🧒**見習い**150、👷**坑夫**520、🧑‍🔧**職人**1,160、🕴️**監督**640。同じ種類を何人雇っても、契約料は同じです。
  - **作業員の稼ぎと鉱石**: 作業員は、**1時間に 見習い1.8・坑夫10.05・職人23.55 ペリカ**（これが作業員の稼ぎ）を稼ぎ、**働いた1時間ごとに鉱石を1回掘ります**。作業員の稼ぎは契約料の約3〜5割しかなく、**作業員の稼ぎだけでは赤字**です。⚫**石炭**（売値3。**働いた1時間の約4割で、どの作業員も掘れる**）・🟤**銅**（売値60）・⚪**銀**（240）・🟡**金**（1,200）・💎**ダイヤ**（9,000）・🌟**伝説の鉱石**（90,000）が出ると、その売値が稼ぎに入ります（外れもあります）。
  - **平均は赤字**: 毎日受け取る人の1日で、作業員の稼ぎと鉱石を合わせた期待値は、契約料の約83〜87%です。レアが出た日は大きく黒字で、**運よくレア鉱石を引いた人だけが、大きく黒字**になります。上位の作業員ほど、レアが出やすくなります。
  - 🕴️**監督**: 自分では掘らず、全員のレア鉱石と発掘品の出やすさを +25% にします（人数に上限はありません）。作業員の稼ぎは増えません。
  - 🏺**発掘品**（コレクション用）: 作業員（見習い・坑夫・職人）は、鉱石を掘るのとは別に、働いた**1時間ごとに、まれに発掘品**を見つけます。見つけた発掘品は、**ペリカにならず、持ち物に入ります**（「受け取る」で入ります。稼ぎが 0 でも受け取れます）。種類と、1時間ごとの出る確率（職人の場合。**坑夫は0.8倍・見習いは0.5倍**。🕴️監督の運も効きます）は、🐚**三葉虫の化石** 0.33%・🦴**恐竜の骨** 0.17%・☄️**隕石の欠片** 0.067%・🏺**古代文明の壺** 0.027%・👑**王家の黄金冠** 0.0067%・🔮**竜の涙** 0.0017%（目安の価値は、1,500・4,000・10,000・25,000・60,000・100,000ペリカ）。**職人1人なら、平均して1週間に1つほど**です。**売値は決まっておらず、ショップの競売の画面で、プレイヤーどうしが売り買い・競りをします**（値段は、目安の価値の0.1〜5倍。同じ2人の取引は1日10万まで）。ペリカを新しく作らないので、発掘品の値段は、買う人が払ったペリカで決まります。**👑と🔮は、受け取ったとき、チャンネルに公開で知らせます**。
  - ✨**発掘品の効果（バフ）**: 発掘品は、**持ち物に入っている間、1個ごとに +1% の効果**がつきます（**同じ種類を複数持てば重なります**。たとえば🦴を3個で作業員の稼ぎ+3%。6種類そろえると、6つの効果が同時に効きます）。
  - 🧬**合体**: **同じ発掘品を10個集めると、★が1つ増えた1個に合体**できます（`/地下 作業` の画面の「🧬 発掘品を合体」。出品中の品は数えません）。**★が1つ増えるごとに、効果と目安の価値が10倍**（★なし +1% → ★ +10% → ★★ +100% → ★★★ +1000%。★★★が最上位）。★の数は名前の横に付き、競売の画面で売り買いもできます。10個のまま持っていても効果の合計は同じなので、合体は持ち物を減らして、レアな品を作るためのものです。高価な★つきは、取引の値段の上限が、同じ2人の1日の上限（10万）で止まります**出品中（預かり中）の品は、持ち物にないので、効きません**（取り消すと、また効きます）。🐚三葉虫の化石＝「働く」1回の稼ぎ・🦴恐竜の骨＝作業員の稼ぎ・☄️隕石の欠片＝作業員の鉱石と発掘品の出やすさ・🏺古代文明の壺＝疲労の回復の速さ・👑王家の黄金冠＝デイリーボーナスの額・🔮竜の涙＝競馬の賞金（馬主として受け取る額）。小さな上がり幅（1回の稼ぎが10ペリカのときの 10.1 など）は、確率で切り上げて、**平均では、そのとおり+1%**になります。
  - 掘った鉱石は、「未受け取り」に入り、画面の「💎 作業員の掘り出し」に出ます。「受け取る」で、売値が手元に移ります。**ダイヤ以上を受け取ったときは、チャンネルに公開で知らせます。**
  - 画面の「📜 最近の掘り出し」に、**いつ・どの作業員が・何を掘ったか**が、新しい順に出ます（石炭は除く。直近40件を残します）。抽選は、画面を操作したときにまとめて行われるので、時刻は、働いた時間のあいだの1時間ごとの枠にそろえて出します。
  - 🔁**自動更新**（最初はオン）: 契約が切れたら、貯まっている稼ぎから契約料を払って更新します（足りなければ手元から）。それでも払えない・オフにしているときは、その作業員は退職します。久しぶりに見に来ても、切れていた期間の契約料は取られず、更新は1回分です。
  - 人数は、最初は **5人**まで。🏠**寮**を強化すると +1人ずつ（2,000 / 6,000 / 15,000 / 40,000 / 100,000。最大10人）。枠が埋まったら、契約の早く切れる人から**解雇**（契約料は戻りません）して、強い人に替えます。
  - 稼ぎは、ほかの収入と同じく、借金があれば天引きされます（破産しても、作業員は差し押さえません）。
  - 数字は、シミュレーションで確かめて決めています。`core/labor.py` の作業員の稼ぎ（`WORKER_RATE`）・鉱石の表（`ORES`・`ORE_POWER`）・契約料（`CONTRACT_FEE`）で調整できます。
- 数字は `core/labor.py` で調整できます。
