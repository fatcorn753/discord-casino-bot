# 配信（`/配信`）

誰かの配信に、YouTube のようにスパチャを送ったり、配信者の勝ち・負けに賭けたりできます。数字は `catalogs/economy.yaml` の `stream:` が正です。計算は `domain/stream.py` にあります。

## 配信パネル

- 配信者が `/配信 開始` で、タイトル（と、あれば配信の URL）を決めて、チャンネルに配信パネルを出します。Discord の画面共有でも、YouTube や Twitch などの外の配信でも使えます。
- パネルには、配信している場所（Discord のボイスチャンネル）も出ます。押すと、その VC に入れます。
  - 配信者がボイスチャンネルに入ってから `/配信 開始` すると、そのチャンネルを場所にします。
  - ボイスチャンネルに入っておらず、URL も指定しなかったときは、Bot が配信用のボイスチャンネル「📺 〇〇の配信」を、パネルを出したチャンネルと同じカテゴリに作ります。配信者には、作ったチャンネルを本人だけに見える案内で知らせます。配信を終えるか、自動で閉じると、Bot が作ったチャンネルは消えます（配信者が自分で入っていたチャンネルは消しません）。
  - 配信用のチャンネルを作るには、Bot に「チャンネルの管理」の権限が要ります。なければ、パネルはそのまま出して、配信者に「VC に入ってから始めてください」と案内します。
  - URL を指定した外の配信（YouTube など）で、配信者がボイスチャンネルにいなければ、場所は出さず、チャンネルも作りません。
- パネルには、スパチャの合計と、いまの勝負の賭けの様子（勝ち・負けそれぞれの合計と、当たったときの倍率の目安）が出ます。
- 1人が同時に出せるパネルは1つです。配信者メニューの「⏹️ 配信を終える」で閉じます。閉じ忘れても、24時間（`max_hours`）たつと自動で閉じます。
- パネルのボタンは、Bot が再起動しても動きます。

## スパチャ

- パネルの「💸 スパチャ」から、金額とメッセージ（150文字まで）を入れて、配信者に送ります。
- お金の動きは `/ペリカ 送金` と同じです。手数料10%は送る側が上乗せで払い、1日に送れる合計の上限（20,000ペリカ）は送金と合わせて数えます。ゲームで3回以上遊んだ人だけが送れ、借金があると送れません。履歴には送金として出ます。
- 最低額は100ペリカです（`tip_min`）。配信者は自分の配信に送れません。
- 送ったスパチャは、チャンネルに出ます。額が大きいほど、目立つ色になります（青 → 水色 → 緑 → 黄 → 橙 → 赤紫 → 赤）。

## 勝敗の賭け

1. 配信者が「🎛️ 配信者メニュー」→「🎲 勝負を始める」で、勝負（例: 3戦目・ボス戦）の賭けの受付を開きます。
2. 見ている人が、パネルの「🏆 勝ちに賭ける」か「💀 負けに賭ける」で賭けます。賭け金は、精算まで預かります。
3. 勝負が始まったら、配信者が「🔒 賭けを締め切る」を押します。
4. 勝負が終わったら、配信者が「🏆 勝った」「💀 負けた」のどちらかで勝敗を決めます。決められないときは「↩️ 無効にする」で、全員に賭け金を全額返します。

決まっていない勝負があるうちは、次の勝負を始められません。配信を終えたとき、自動で閉じたときに決まっていない勝負は、無効になり、賭け金は全額返ります。

### 配当（山分け）

- 負けた側の賭け金の合計から、帝愛が5%（`rake`）を控除します。残りを、当てた人で、賭けた額に比例して分けます。控除と、山分けの端数は、帝愛銀行の収入になります。
- 当てた人には、自分の賭け金が必ず戻ります。控除は負けた側からだけ引くので、当てて損することはありません。
- 片方にしか賭けがなければ、勝負にならないので、全額返します。新しくペリカを作ることはありません。

例: 勝ちに A が 1,000・B が 3,000、負けに C が 2,000 賭けて、配信者が勝った場合です。負けた側の 2,000 から控除 100 を引いた 1,900 を、A と B で 1:3 に分けます。A は 1,000 + 475 = 1,475、B は 3,000 + 1,425 = 4,425 を受け取ります。

### 八百長への対策

勝敗は配信者が決めるので、配信者がわざと負けて、仲間の「負け」の賭けを当てさせる八百長ができます。次の決まりで、儲けを小さくしています。

- 配信者本人は、自分の勝負に賭けられません。
- 1人が1回の勝負に賭けられるのは、合計10,000ペリカまでです（`bet_max`）。同じ側になら足せますが、反対の側には変えられません。
- 賭けの最低額は100ペリカです（`bet_min`）。借金があると賭けられません。

## 機能の停止

`/運営 機能 停止` で「配信」を止めると、新しい配信パネル・スパチャ・賭けを断ります。配信者メニュー（勝敗を決める・無効にする・配信を終える）は止めていても使えるので、預かった賭け金は必ず精算できます。
