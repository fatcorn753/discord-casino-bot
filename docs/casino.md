## チンチロのルール
サイコロ3個を振って役で勝負します。親（ディーラー）が先に振り、そのあとあなたがボタンで振ります。

| 役 | 内容 | 勝ったときの倍率 |
|---|---|---|
| ピンゾロ | 1-1-1 | 5倍 |
| 嵐（アラシ） | 2〜6のゾロ目 | 3倍 |
| シゴロ | 4-5-6 | 2倍 |
| 目 | ペア＋1つ。残った1つが目の数（6が最強） | 1倍 |
| 目なし | 役なし。3回まで振り直せる | — |
| ヒフミ | 1-2-3。**負け役**で、負けると相手の役の倍率が**さらに2倍**（例: シゴロ対ヒフミは4倍） | — |

- 強さは「ピンゾロ ＞ 嵐 ＞ シゴロ ＞ 目 ＞ 目なし ＞ ヒフミ」。同じ強さは引き分け（賭け金が戻る）。
- 負けたとき、相手の役が嵐・ピンゾロなら 3倍・5倍払い（ヒフミで負けるとその2倍で、最大10倍）。賭け金のほかに払う分は、まず残高から引かれ、足りない分は強制執行（下の「借金と身分」）のあと、**帝愛への借金**になります。
- 借金は、**収入（ゲームの純利益・デイリー・ミッション報酬・受け取った送金など）の3割が天引き**されて返ります。借金がある間は、ショップの購入・証券の購入・送金・クイズの出題はできません。ランキングの総資産は借金を引いた額です。くわしくは[借金と身分](teiai.md#借金と身分帝愛ファイナンス)。
- **目なし同士は親の勝ち**です（これが胴元の取り分）。

結果の乱数は OS の乱数（`SystemRandom`）で、予測や再現はできません。払い戻しの端数（1.95倍や0.3倍など）は切り捨てです。

## パチンコ（打ち出し型）

実機に近づけた作りです。**1セット = 100発**を打ち出し、賭け金がそのセットの代金です。

- 玉は1発ごとに、約**7%**がスタートに入ります（平均7回転/セット）。**入らない玉は、釘やハズレの穴に落ちます**。1回も入らないセットもあります
- 入った数だけ回転します。回転ごとに、予告の色（青<赤<金）とリーチの格（ノーマル<スーパー<プレミアム）が出て、**出るほど当たりやすく**なります。リーチなしで突然揃う「サプライズ当たり」もあります
- 当たると**大当たり**。出玉は賭け金の**2倍（69.5%）・10倍（26.5%）・30倍（4%）**のどれかで、**確変の連チャンが50%で続きます**（平均2連）。1セットの払い戻しは、出玉の合計です（**上限はありません**）
- 当たるセットは約**9%**。還元率は100%を超えないよう調整してあります
- **`回数`（1〜10）**で、同じ賭け金のセットを続けて打てます。賭け金 × 回数 が、そのまま賭け金になります（残高が足りないと始まりません）。結果の下の「🎰 ×5連続」（5セットのあとは「×10連続」）のボタンでも続けられます。連続して打っても、**1回の遊び**として数えます（ミッション・連勝・週間ランキングは1回分）
- 結果は賭けた時点で決まり、先に精算します。**当たった回転だけ**を、実機のように見せます。リールは「回っている／止まっている」の状態を持ち、左右が同じ絵柄で止まると**リーチ**、そのあと出目が決まるまで左右は変わりません（変わるのは、再回転する擬似連・全回転のときだけ）。**3つ揃うのは最後の1コマだけ**で、揃ったら演出は終わり、すぐ当たりの宣言になります。演出は、格（リーチなし・ノーマル・スーパー・プレミアム）ごとの台本から**1本を選んで**流し、予告・擬似連（0〜4回）・カットイン・発展の種類は回ごとに変わります（全部が毎回流れるわけではありません）。当たりの宣言と連チャンの演出（当たりの宣言と連チャン連チャン数の大表示・5連や10連の節目・終了のまとめ）は、演出が終わったあとに出します（ハズレの回転は「〇回転 経過」のように数字でまとめ、外れたリーチは文字で触れるだけです）。リーチの当たりでは、**復活演出**が出ることがあります（いったん3つ目がずれて「外れた」ように見せて、「それでも!!!」「と、思っていたのか」などの台詞のあと、再回転して揃います。リーチがノーマルで10%・スーパーで25%・プレミアムで30%。当たったときだけで、ハズレの回転には出ません。当落は演出より先に決まっていて、変わりません）。当たりが複数あっても省略せず、約60コマ（約66秒）分の上限まで順に見せ、超えた分は数でまとめます。連続投入でも、当たったセットを出玉の大きい順に、上限まで見せます
- 持ち主向けの `/運営 還元率` のレベルは、セットごとに勝ち分へかかります

## クイズ（時事ネタ・豆知識で稼ぐ）

`/クイズ 挑戦` で、まだ答えていない問題が1問ずつ、自分だけに見える形で出ます。4択のボタンで答え、**正解すると問題ごとの報酬**（既定100ペリカ）がもらえます。

- 1問につき**1人1回だけ**です。不正解でもやり直せません。答えたあとに、正解と解説が出ます
- 公開された問題に誰かが答えると、その場で「⭕ 〇〇が正解！」「❌ 〇〇が不正解…」が**みんなに見える形で**出ます（選んだ答えと正解は出しません。解説つきの結果は本人だけに見えます）
- 選択肢の並びは、問題を登録するときに1回だけシャッフルして固定します（誰が見ても同じ並びです）
- 登録すると、**全サーバーの告知チャンネル**（ランキング掲示のチャンネル、無ければシステムチャンネル）に、問題文と A〜D のボタンが投稿されます。**その場でボタンを押して答えられます**（結果は本人だけに見えます）。再起動しても、押せます
- 問題は全サーバー共通です。報酬は、答えたサーバーの口座に入ります（借金があれば、収入の3割が天引きされます）
- 持ち主の問題の報酬はシステムが払います。稼げる量は、問題の数で決まります（回答数の上限は別にありません）
- 通常債の売却は、`/証券 保有` の売却ボタンか、`/証券 決済`（ポジションで債券の番号を選ぶ）で行います
- ミッション・連勝・週間ランキング・突発イベントには数えません

**みんなが出題する（`/クイズ 出題`）**

誰でも自分の問題を出せます。入力フォームに、問題文・選択肢（4行。1行目が正解）・解説・「報酬 / 期間」（例: `100 / 2日`。期間は省略可）・「正解・不正解の文言」（省略可）を入れます。
- **正解・不正解の文言**: 2行で、1行目が正解のとき、2行目が不正解のときの見出しの言葉です（各20文字まで）。「⭕ 正解！」「❌ 不正解…」の「正解！」「不正解…」の部分が、結果の画面とみんなに見える通知で差し替わります。省略した方は、今までどおり「正解！」「不正解…」です（片方だけも書けます）

- 問題には、**制作者の名前**（登録したときの表示名。持ち主の問題も同じ）が「出題: 〇〇」と出ます
- 問題は、出したチャンネルに投稿され、ボタンで答えられます。**そのサーバーの中だけ**に出ます（ペリカがサーバーごとの口座なので）
- 正解1人への報酬（**1ペリカ以上。上限なし**）は、**出題者本人のペリカから払われます**。払うたびに出題者の残高から引き、**残高が足りなくなったら、足りない分は出題者の借金**になります（回答者には報酬を全額払い、公開メッセージに「⚠️ 出題者の残高が足りないため…借金になりました」と出ます）。借金は、出題者に入るお金から先に自動で返済され、返し終わるまで、出題と送金ができません。借金の上限はありません
- **正解の報酬をもらえるのは、ゲームを3回以上遊んだ人だけ**です（複数アカウントでペリカを作るのを防ぐ、送金と同じ条件）。3回未満の人も正解にはなりますが、報酬はなく、出題者は払いません。出題者の受け取り（下）にも数えません。持ち主の問題には、この条件はありません
- **出題者は自分の問題に答えられません**。有効な期間は1分〜7日（「90分」「6時間」「2日」の形。空欄なら3日）で、正解者数の上限はありません
- **回答者が2人以上**になると、出題者にシステムから次の3つが入ります（2人に満たないと、出題報酬はありません）。**回答のたびに**、その時点の合計との差が**その場で**払われ、公開メッセージに「💰 出題者 +〇〇（累計 〇〇）」と出ます。正答率が40%から離れると合計が下がり、その差額は出題者の残高から戻されます（残高の範囲まで）。期限・取り下げのときは、最終結果をまとめて出します
  - **基本報酬** 100ペリカ × 倍率
  - **正答率ボーナス** 最大200ペリカ × 倍率
  - **参加報酬** 回答者1人につき「報酬」ぶん（報酬 × 回答者数）。上限なし。人気の問題ほど増えます
  - **倍率** は、報酬が高いほど基本とボーナスを増やします（√(報酬÷100)。報酬100で×1、400で×2、1000で約×3.2。25なら×0.5）
  - ボーナスと参加報酬には、正答率が**40%**に近いほど大きくなる係数がかかります（ちょうど40%で満額、そこから離れるほど減り、0%と80%以上では0）。誰も解けない問題や簡単すぎる問題では稼げません
  - 例（報酬100・回答10人）: 正答率40% → 支払い400、受け取り1,300（100＋200＋1,000）で **+900**。20% → +500。60% → +100。70% → −300（簡単すぎて正答率が上がると赤字）
  - 例（報酬1,000・回答10人・正答率40%）: 支払い4,000、受け取り316＋632＋10,000＝10,948で **+6,948**。報酬を上げるほど、黒字（と赤字）の幅が広がる「ハイリスク・ハイリターン」です
  - 正解者への報酬は、出題者の残高から払われます。報酬が高い問題は、出題者の残高が尽きると借金になります
- 結果（参加人数・正答率・出題報酬と、**正解者・不正解者の一覧**）は、問題を投稿したチャンネルに、出題者へのメンションつきで出ます
- 乱用を防ぐため、1人が**同時に出せるのは2問まで、24時間に3問まで**です。借金中は出題できません
- 不適切な問題は、持ち主が `/運営 クイズ 削除` で消せます（出題報酬は出ません）
- 数字は `core/quizpay.py` で調整できます

**一括登録のファイルの書き方**（問題は `---` だけの行で区切ります。`#` で始まる行はメモです）

```
問題: 2026年に開かれる〇〇は？
正解: 正しい選択肢
不正解: まちがいの選択肢1
不正解: まちがいの選択肢2
不正解: まちがいの選択肢3
解説: 解説（なくてもよい。次の行に続けて書けます）
報酬: 100        ← なくてもよい（既定100。1以上。上限なし）
期間: 2時間      ← なくてもよい（なければ無期限。「90分」「2時間」「1時間30分」「3日」の形。1分〜365日）
                      「時間: 2」「日数: 3」「分: 90」と、単位を見出しにして数字だけ書いてもよい
---
問題: 次の問題…
```

**問題の登録（Bot の持ち主だけ）**

| コマンド | 内容 |
|---|---|
| `/運営 クイズ 追加` | 入力フォームが開きます。「告知」を「しない」にすると、告知を出さず `/クイズ 挑戦` だけに出ます（まとめて登録するとき用）。問題文・選択肢（4行。**1行目が正解**）・解説・「報酬 / 期間」（報酬は1以上（上限なし）、期間は「90分」「2時間」「3日」の形。例: `100 / 3日`。期間を省くと無期限）・「正解・不正解の文言」（2行。省略可）を入れます |
| `/運営 クイズ 一括追加` | 問題を書いた**テキストファイル（.txt、UTF-8）を添付**して、まとめて登録します。送ると一覧のプレビューが出て、「登録する」を押すまで登録しません。1つでも誤りがあると**1問も登録せず**、何問目のどこが誤りかを返します。すでに登録済みの問題文は、重複として断ります（同じファイルを2回送っても二重になりません）。`告知` を「する」にすると、全サーバーに1問ずつ出します（既定は「しない」）。一度に30問まで |
| `/運営 クイズ 一覧` | 登録した問題（新しい順に15件）。正解・報酬・期限・正解した人数が出ます |
| `/運営 クイズ 削除` | 番号を指定して削除します（回答の記録も消えます） |

時事ネタは、有効な期間を入れておくと、古くなった問題が自動で出なくなります。分や時間の単位でも指定できます。

## 抽選（持ち主が開催）

Bot の持ち主（`owner_ids`）が、Bot とのDMで `/運営 抽選 開催` を使って始めます。参加費は500以上（上限なし）で指定するか、省略すると500〜3,000のランダムです。募集時間は分で指定します（省略で60分）。

- 参加は、投稿の「🎟️ 参加する」ボタンです。**参加費は押した時点で先に引かれ**、全員同じ額です。借金があるときは参加できません
- 締切に、参加者から1人を等確率で選びます。当選者が、集めた参加費の**全額**を受け取ります（手数料なし）
- 参加者が2人に満たないとき、`/運営 抽選 中止` したときは、全員に全額を返します
- 投稿がコメントで流れたら、`/運営 抽選 再掲示` で告知チャンネルに出し直せます（古い投稿は消え、参加者はそのままです）
- 募集中は1サーバーに1つだけです。開催状況と参加者は保存され、Bot を再起動しても続きます（締切を過ぎていれば、起動後に結果を出します）
- 参加費を預けている間は、ランキングの総資産がその分だけ減って見えます
- ミッション・連勝・週間ランキング・突発イベントには数えません

## 突発イベント

1日に1回、**日本時間の12時〜23:30のどこか**で、**1つのゲームだけ30分間**、勝ったときの勝ち分（払い戻し − 賭け金）が**1.5倍**になります。上乗せは1回につき最大10,000ペリカです。

- どのゲームで、何時に始まるかは、日付とサーバーごとに決まります（運営の設定は不要）。
- 開始と終了は、ランキング掲示のチャンネル（無ければサーバーのシステムチャンネル）に自動で投稿されます。メンションは付きません。
- Bot が止まっていて開始を逃した日は、告知もイベントも行いません（終了後に起動しても何も投稿しません）。
- 負けたときや引き分けには、何も付きません。

## 還元率のレベル（持ち主が変える）

持ち主は、Bot とのDMで `/運営 還元率 設定`（サーバー・ゲーム〔または「すべて」〕・レベル）を使い、ゲームごとの還元率を **1〜6** の6段階で変えられます。**3が標準（いまの設定）**です。`/運営 還元率 一覧` で、いまのレベルと還元率の目安を見られます。

- **勝ったときの勝ち分だけ**を、一定の倍率で増減します。負け・引き分けは変わりません
- 1段階で、還元率が約**4ポイント**動きます（レベル1で約−8、レベル6で約+12）。ゲームごとに倍率を計算するので、どのゲームも同じ幅で動きます（ルーレットは賭け方ごとに計算します）
- 目安: スロット 88%〜108% ／ ルーレット（赤・黒など）89%〜109% ／ パチンコ 約92%〜112% ／ チンチロ 約90%〜110% ／ ブラックジャック 約84%〜104%（ブラックジャックとチンチロは、打ち方で変わる目安です）
- 設定はサーバーごとです。レベル4以上では、還元率が100%を超えるゲームがあり、遊ぶだけでペリカが増えます
- ユーザーには、レベルは見せません
