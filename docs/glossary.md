# 用語集

資産と証券まわりの用語の正本です。画面・ヘルプ・README・ほかの docs は、ここの言葉にそろえます。

## 資産（貸借対照表）

`/ペリカ ランキング`・`/ペリカ 残高`・`/ペリカ 内訳` は、資産を貸借対照表（B/S）の区分で数えます。

| 用語 | 意味 |
|---|---|
| **流動資産** | すぐペリカにできる資産。現金・預金（帝愛信託）・株式（現物の時価＋信用取引の評価額）・債券（元本）・オプション（評価額）・未収金（受け取る前の地下作業の稼ぎ）・預け金（競りへの入札）・貸付金（個人への貸付） |
| **固定資産** | 持っていて、すぐにはペリカにしない資産。持ち物（買値）・発掘品（目安の価値）・競走馬（購入価格＋引退金の見込み）・会社（会社資金＋事業所の建設費）・地下作業の工具・寮（これまでの強化費用） |
| **総資産** | 流動資産 ＋ 固定資産（負債を引く前） |
| **負債** | 借入金。帝愛への借金（溜まった利息を含む）と、個人からの借入 |
| **純資産** | 総資産 − 負債。ランキングの既定の並び順（もう1つのボタンは流動資産の順） |
| **金融純資産** | 現金 − 帝愛への借金 ＋ 預金・株式・債券・オプションの評価額。🟡 富豪の表示だけに使う（固定資産と個人間の貸し借りは含まない） |

- 「流動資産 ＋ 固定資産 − 負債 ＝ 純資産」は、常に一致します（`tests/infra/test_net_assets.py`）。
- 項目と区分の対応は `domain/types.py` の `LIQUID_KEYS`・`FIXED_KEYS`・`LIABILITY_KEYS`、表示名は `cogs/shared/texts.py` の `PART_LABELS` です。
- 以前の「ファイナル総資産」は、いまの**純資産**です。以前のランキングの「純資産」は、いまの**金融純資産**にあたり、ランキングには出しません。

## 信用取引

| 用語 | 意味 |
|---|---|
| **有効証拠金** | Σ（建玉の担保 ＋ 含み損益）＋ 代用有価証券の評価 |
| **必要証拠金** | 建玉のリスク量。銘柄どうしの相関を織り込んで計算する（[口座の余力](stocks.md#口座の余力クロスマージン)） |
| **余力** | 有効証拠金 ÷ 必要証拠金。建玉のリスク量に対して、担保が何倍あるか。130% 未満では新しく建てられず、100% を割ると強制決済 |
