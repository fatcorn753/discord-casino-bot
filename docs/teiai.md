[← README に戻る](../README.md)　／　[ドキュメントの一覧](../README.md#詳しい仕様docs)

## ペリカのお金の流れ

運営口座の仕組みは廃止しました（ユーザーが負けた分・勝った分は、どこにも記録されません）。デイリー・ミッション・初期支給は、そのまま残高が増えます。
- ペリカはゲーム内の数字で、現実のお金とは無関係です。現実のお金に換える、売る、買うといった使い方はできません

## 借金と身分（帝愛ファイナンス）
借金は、**帝愛ファイナンスからの借金**です（プレイヤー同士の `/貸付` とは別）。数字は `core/teiai.py` で調整できます。

- **強制執行**: チンチロの倍払いなどで払えないとき、**現金 → 空売り・信用買い → 証券（現物・全銘柄）→ 通常債（古い順）**の順に差し押さえて充て、それでも足りない分が借金になります。現金で足りれば、証券には手を付けません。結果の画面に、差し押さえたものが出ます。
- **種銭**: 借金があって手元が空になると、帝愛が**種銭 3,000ペリカ**を貸し付けます（借金に加わります）。「これで取り返してこい…！」手元が空でなくても、種銭の枠（3,000）に足りなければ、**いつでも枠まで借りられます**（`/ペリカ 帝愛` の「種銭を借りる」。借金になり、地下労働者に落ちます）。
- **帝愛の信用でダブル**: ブラックジャックのダブルで手元が足りないとき、不足分（**3,000ペリカまで**）を帝愛から借りて強行できます（確認ボタンつき。借金になります）。破産者・破産猶予中は使えません。
- **天引き**: 収入の**3割**が、借金の返済に天引きされ、残りは手元に残ります。ゲームは、賭け金は全額戻り、**純利益の3割だけ**です（負けや引き分けからは引きません）。デイリー・ミッション報酬・クイズの報酬・抽選の当選・受け取った送金・債券の利息も収入です。管理者の付与・借りたお金・賭け金の返金・証券や債券の売却は、収入ではありません。
- **帝愛の利息（トイチ）**: 借金には、**1日ごとに借金の1%**（10日で1割）が加わります（単利。日数を満了した分だけ）。しばらく来なかった人は、**1回に数えるのは10日分まで**で、超えた日は数えません（放置で借金が膨らまないように）。利息で借金が増えるのは **14,999ペリカまで**で、利息のせいで破産猶予に入ることはありません。履歴に「帝愛の利息」が残ります。借金がなくなると、数え始めの時刻は忘れます。
- **デイリーのピンハネ**: 借金中は、デイリーの**2割を帝愛が没収**します（借金の元本は減りません）。残りの3割が天引きされ、手元が種銭の枠（3,000）に満たなければ、枠まで貸し付けます。ピンハネは、**帝愛の胴元の口座**に入ります（下の「帝愛の胴元の口座」）。
- **返済**: `/ペリカ 返済` で、手元のペリカから、いつでも返せます（金額を省くと、返せる限り全額）。
- **身分**（`/ペリカ 残高` に出ます）: 🟢 **カタギ**（借金も延滞もない）／🟤 **地下労働者**（帝愛の借金か、貸付の延滞がある）／🔴 **破産者**（自己破産のあと、**帝愛の借金が残っている間だけ**。**完済すれば、すぐ、カタギ（延滞があれば地下労働者）に戻ります**）。**貸付を借りられないブラックリストは、身分とは別で、完済から7日続きます**。さらに、カタギで**純資産（現金・預金・株・債券など、借金を引いたあと）が 1,000,000 以上**の人は 🟡 **富豪** と表示されます（**表示だけで、ゲームの条件や効果は何も変わりません**。資産が減れば外れます）。
  - 借金や延滞で地下に落ちても、**連続ログインは途切れません**（デイリーを毎日受け取っている限り続きます）。
  - 地下労働者・破産者の間は、買った**称号・カードの色とアイコン・演出の変更品・コレクションが差し押さえ中**で、見えません（記録は残り、カタギに戻ると使えます）。残高カードには「🔒 差し押さえ中」と出ます。
  - **ニックネームの末尾に、`【地下労働者】` `【破産者】` `【富豪】` が自動で付きます**（2分おきに確認。称号の表示を選んでいなくても付きます）。完済してカタギに戻ると、元のニックネームに戻ります（称号の表示を選んでいる人は、富豪でも選んだ称号が優先されます）。サーバーの持ち主・Bot より上のロールの人・Bot に「ニックネームの管理」権限がないサーバーでは、付けられません。ランキングでは、名前の横に 🟤 🔴 🟡 が付きます。
- **借金中の債券の満期**: 債券の満期で戻る元本は、借金があれば**全額が返済に充てられ**ます（利息は、収入として3割だけ天引き）。満期の元本で、天引きをのがれることはできません。
- **借金中の `/貸付`**: 帝愛の借金があっても、借りられます（借り換え）。回収の順番は、**帝愛 → 延滞中の `/貸付`（古い順）**です。借金中の送金・クイズの出題は、これまでどおりできません。
- **自己破産**（`/ペリカ 破産`。確認ボタンのあとに実行。**元に戻せません**）:
  1. **全財産（現金・空売り・信用買い・証券・債券）と、ショップの全品（称号・カード・演出・コレクション・消耗品）を差し押さえ**ます。売れないジャンク債と、ショップの品は、購入額（元本）の**50%**で換金します。
  2. 換金した合計を、**帝愛 → 貸付（古い順）**の順に配当します。あまれば、手元に残ります。
  3. **貸付の残りは免責**（貸した人の損）。**帝愛の借金は、残っていても10,000ペリカまで圧縮**されます（完全には消えません）。
  4. 身分が🔴**破産者**になります（借金が残っている間）。**貸付は、完済して7日たつまで借りられません**（破産で貸付を踏み倒した人が、すぐ別の貸付を借りるのを防ぐためです）。
  - 借金も貸付の借り入れもないと、破産できません。破産のあと、手元が空で借金が残るなら、種銭が貸し付けられます。
  - **少額の借金でも破産できます**（債務超過の基準はありません）。たとえば、財産が何もなく、借金100・手元0で破産すると、差し押さえるものが無いので借金は100のまま残り、そこへ種銭（3,000）が貸し付けられて、借金3,100・手元3,000になります。手元に運転資金が渡るので、すぐ勝負へ戻れますが、借金は増えます。
  - 破産すると、**名前の色ロールが外れ、ニックネームに `【破産者】` が付く**のは、その場で行います（権限や位置の都合で失敗したときは、2分おきの確認で付け直します）。
- **🚢 海外逃亡チャンス！！**（`/ペリカ 帝愛` の画面のボタン）: 帝愛の借金が**5,000ペリカ以上**のとき、確認のあとで押せます。船の ASCII アートが進んで、数秒後に「成功！」か「失敗！」が、公開メッセージで出ます。
  - **成功（1%）**: 全財産とショップの全品を**置いていき**（自己破産と同じ差し押さえ・貸付は免責・CDS は無効・貸付のブラックリスト）、帝愛の借金が**全額ゼロ**になります（自己破産のように10,000は残らず、種銭も貸されません）。
  - **失敗（99%）**: **罰金**（借金の10%・最低1,000ペリカ）が借金に加わり、**24時間は、もう試せません**。罰金で借金が15,000以上になると、破産猶予に入ることがあります。
  - 破産者は使えません。**チャンスは1人につき通算2回まで**（失敗も1回に数えます。使い切ると押せません）。当たり外れは押した時点で決まります（演出は見せ方だけ）。
- 本番には、すでに借金がある人がいますが、そのまま帝愛の借金として扱います（次の収入から、新しい天引きに変わります）。

## 帝愛銀行・破産猶予・CDS

銀行も保険も、**帝愛**に一本化しています。操作は `/ペリカ 帝愛` の画面だけです。数字は `core/teiai.py` で調整できます。

### 帝愛銀行（預金と取り付け騒ぎ）
- **預金**: 🟢 カタギだけが預けられます（100ペリカ以上）。預金は純資産（ランキング）に数えます。
- **帝愛の胴元の口座**: 銀行の手元（預金の準備）とは**別に**、帝愛が自分のために持つ口座です（サーバーごとに1つ）。**ピンハネ**（借金中の人のデイリーの2割と、地下作業の受け取りの1%）が、全額ここに入ります。残高と、ピンハネの合計は、`/ペリカ 帝愛` の画面に出ます。銀行の預金者の利回りや、取り付け騒ぎの計算には、使われません。
- **部分準備**: 預けられた額の**20%だけ**が手元の現金に残り、残りは「地下融資」に回ります。地下融資は、1時間に2%ずつ現金に戻ってきます。
- **利回り**: ペリカは新しく作りません。次の3つが、預金額に応じて預金者に分配されます（預金者がいなければ、カジノの負け分は、これまでどおり消えるだけです）。
  - **CDS の掛け金**の半分
  - カジノで**プレイヤーが負けた額の3%**
- **利用可能現金** = 手元の現金 − **引当金のロック**。ロックされるのは、破産猶予中の人への CDS の配当見込み（その人の借金の半分まで）と、借金のある人の借金の5%です。
- **取り付け騒ぎ**: 引き出せるのは利用可能現金までで、**早い者勝ち**です。準備率（利用可能現金 ÷ 預金総額）が15%未満なら🟡、5%未満なら🔴、利用可能現金が0以下なら🚨**支払停止（預金封鎖）**で、引き出せません。誰かが破産猶予に入ると、引当金がロックされて準備率が急に下がります。`/ペリカ 帝愛` に、準備率のメーターと猶予中の人の一覧が出ます。
- **AIG ショック**: CDS の配当が手元の現金で足りないときは、**預金者の預金が一律に減らされて**払われます（銀行は、CDS を必ず払います）。
- 借金で強制執行・自己破産になると、預金も、引き出しの制限なしに差し押さえられます（現金の次）。

### 公開される結果
盛り上がる結果は、チャンネルに**公開**されます（誰がやったかも出ます）。失敗や、戦略が見えるものは、本人だけです。
- 公開: **自己破産の結果**（🔴）、**種銭を借りた**（💸）、**他人への CDS**（「💀 ○○ が △△ の破綻に賭けた」。掛け金とオッズも出ます）、**債券の売却**。買い・売り・信用取引・オプションの注文の結果は、もともと公開です。
- 本人だけ: 預金・引き出し、`/ペリカ 帝愛` の画面、**自分への CDS**、`保有`・`市況`、エラー、確認画面。

### 破産猶予（取り立てのカウントダウン）
- 帝愛への借金が **15,000ペリカ以上**になると、**24時間の破産猶予**に入ります。借金を15,000ペリカ未満へ戻せば、猶予から抜けます。
- 時間切れになると、**自動で強制破産**します（1分ごとに確認。内容は自己破産と同じです）。猶予に入ると、結果の画面に一言が出ます。猶予の間は、新しく借りられません（種銭・帝愛の信用）。
- 延滞中の `/貸付` では、猶予に入りません（借金の額だけで決まります）。

### CDS（破綻保証）
- `/ペリカ 帝愛` の「CDS を掛ける」で、**対象を選び**、掛け金（100ペリカ以上）を払います。**オッズ**は、対象の危険度で決まります（カタギ 15倍 → 借金が増えるほど下がり、最低 1.2倍。信用取引の維持率が150%未満だと、さらに下がる）。掛け金は、銀行の収入です。有効期間は**14日**で、強制破産が起きなければ失効し、掛け金は戻りません。
- **自分に掛ける**: 自分が負けて借金に落ちるとき、**まず自分の資産（現物株・債券など）が差し押さえられ、それでもなお足りない分にだけ**、**配当の見込み（掛け金 × オッズ）を上限に、帝愛が借金を肩代わり**します（1件、使い切り）。現金は渡らず、先に自分の資産を失うので、わざと負けても得をしません（チンチロで負けた分を、帝愛に丸投げすることはできません）。**自分への CDS は、配当の見込みの合計が5万ペリカまで**です。
- **他人に掛ける**: その人が**破産猶予の時間切れで強制破産**したとき、または**猶予に入ってから自分で破産**したときに、配当（掛け金 × オッズ）が出ます。
  - **猶予に入る前**に、その人が自分から `/ペリカ 破産` したときは、配当は出ません（結託して、友達に破産してもらう抜け道の対策）。猶予に入ったあとは、ボタン1つで、買われた CDS を無効にはできません。
  - 同じ人に掛けた全員の配当の合計は、その人の**破産時の借金の50%まで**です（超える分は、一律に減らされます）。友達が実際に失った額より、受け取る額が必ず小さくなります。
  - すでに破産猶予に入っている人、破産者には、新しく掛けられません。買い遅れると、オッズが低くなります。
- ショップの「保険券」は、これまでどおり使えます（CDS には統合していません）。

## 貸し借り（ユーザー同士）

`/貸付 提案` で、相手・金額・**日利**・期間を決めて、貸す提案を出します。投稿の「承諾」を**借りる本人**が押すと成立し、お金が移ります（承諾の期限は24時間）。
- **`/貸付 募集`**: 借りたい人が、金額・日利・期間を決めて募集を出します（チャンネルに公開。同時に出せるのは**1件**、期限は24時間、取り下げも可）。投稿の「貸す」を**最初に押した人**が貸し手になり（確認ボタンあり）、その場で貸す人の残高から借りる人へお金が移ります。貸す瞬間に、借りる人が借りられる状態か（破産者でない・延滞中でない）を確かめ直します。
- **信用情報**（提案・募集の画面に出ます）: 借りる人の**身分**、帝愛への借金、破産猶予中か、**返済の実績**（完済・延滞中・破産で免責になった件数）、いま借りている貸付の件数と元本の残り、破産の履歴。**残高・証券・預金の額は見えません**。

- 金額は100ペリカ以上、日利は0%以上（0.1%刻み）で、**どちらも上限はありません**（貸す人の残高が足りること、借りる人が承諾することが歯止めです）。期間は1〜30日です
- **利息は日割りの単利**です。利息 ＝ 元本 × 日利 × 経過日数（貸した時刻から数えて切り上げ、最低1日、期間が上限）。早く返せば、利息は減ります。**期限を過ぎると、遅延損害金**が付きます（元本 × 遅延日利 × 延滞日数（切り上げ）。遅延日利は、約定日利の1.5倍と2.0%の大きいほう。合計は元本の2倍が上限）。延滞しても得になりません。`/貸付 一覧` に、延滞中の遅延損害金が出ます
- 返済は `/貸付 返済`（金額を省くと、残高の範囲で全額）。返済は、まず元本、次に利息に充てます
- 期限が来ると、**借りた人の残高から自動で回収**します。足りない分は**延滞**になり、借りた人の収入の3割の天引きから、帝愛の返済のあとで、古い順に自動で回収します
- 延滞があるとき、破産のブラックリストの間（破産してから、完済して7日たつまで）は、新しく借りられません（帝愛の借金があるだけなら借りられます）。同時に貸せるのは10件まで、承諾待ちの提案は5件までです（借りる件数に上限はありません）。提案の画面には、借りる人の身分と、帝愛への借金が出ます
- 期限の前日と、延滞になったときに、提案を出したチャンネルに知らせます。`/貸付 一覧` で、自分の貸し借りを見られます
- 担保（証券・称号・債券）は、次の段階で足す予定です
